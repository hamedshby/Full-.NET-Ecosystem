درس 01 · فصل نهم

تفاوت Spring Framework و Spring Boot

مفهوم و نکات کلیدی

فریم‌ورک Spring امکانات اصلی مانند IoC و Dependency Injection، Spring MVC و مدیریت تراکنش را فراهم می‌کند. Spring Boot روی همین فریم‌ورک ساخته شده و با Starterها، Auto-Configuration و راه‌اندازی آسان، تنظیمات دستی را کاهش می‌دهد. Boot جایگزین Framework نیست. از نظر تجربه توسعه وب، با راه‌اندازی ASP.NET Core قابل مقایسه است.

نمونه کد و مقایسه

نمونه کد / راه‌اندازی برنامه Spring BootJAVA
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class PaymentApplication {
    public static void main(String[] args) {
        SpringApplication.run(PaymentApplication.class, args);
    }
}
سؤال مرور درس 01 — نمایش پاسخ

سؤال: آیا Spring Boot مستقل از Spring Framework است؟

پاسخ: خیر. Spring Boot روی Spring Framework ساخته شده و پیکربندی و راه‌اندازی را ساده می‌کند. گزینه B.

درس 03 · فصل نهم

مفهوم Spring IoC Container و Bean

مفهوم و نکات کلیدی

Bean به شیئی گفته می‌شود که Spring Container آن را مدیریت می‌کند. ساخت دستی شیء با new به‌تنهایی به معنی Bean بودن نیست. @Service و سایر Stereotypeها در محدوده Component Scanning کلاس را ثبت می‌کنند. Scope پیش‌فرض یک Bean، Singleton در محدوده Container است؛ Singleton لزوماً Thread-safe نیست.

نمونه کد و مقایسه

نمونه کد / یک Spring BeanJAVA
import org.springframework.stereotype.Service;

@Service
public class PaymentService {
    public void process() {
        System.out.println("Payment processed");
    }
}
نمونه کد / مقایسه دات‌نتCSHARP
builder.Services.AddSingleton<PaymentService>();
سؤال مرور درس 03 — نمایش پاسخ

سؤال: Scope پیش‌فرض Bean با @Service چیست؟

پاسخ: Singleton؛ گزینه B. Bean مشترک بودن به معنی Thread-safe بودن نیست.

درس 04 · فصل نهم

Dependency Injection و Constructor Injection

مفهوم و نکات کلیدی

کلاس نباید Dependency مهم خود را با new بسازد. با Constructor Injection، Container وابستگی ثبت‌شده را به سازنده می‌دهد. اگر Bean فقط یک Constructor داشته باشد، در Spring معمولاً @Autowired لازم نیست. اگر چند Bean سازگار وجود داشته باشند، باید ابهام با روش‌هایی مانند @Qualifier یا @Primary برطرف شود.

نمونه کد و مقایسه

نمونه کد / Repository و Service با Constructor InjectionJAVA
import org.springframework.stereotype.Repository;
import org.springframework.stereotype.Service;

interface PaymentRepository { void save(); }

@Repository
class SqlPaymentRepository implements PaymentRepository {
    public void save() { System.out.println("Payment saved"); }
}

@Service
class PaymentService {
    private final PaymentRepository repository;
    public PaymentService(PaymentRepository repository) {
        this.repository = repository;
    }
    public void process() { repository.save(); }
}
سؤال مرور درس 04 — نمایش پاسخ

سؤال: آیا با تنها یک Constructor به @Autowired نیاز داریم؟

پاسخ: خیر؛ Spring می‌تواند وابستگی را خودکار از طریق Constructor تزریق کند. گزینه B.

درس 05 · فصل نهم

تفاوت @Component و @Service و @Repository

مفهوم و نکات کلیدی

هر سه Annotation برای شناسایی کلاس‌های قابل مدیریت توسط Container کاربرد دارند. @Component عمومی است؛ @Service نقش منطق کسب‌وکار و @Repository نقش دسترسی به داده را نشان می‌دهد. @Repository می‌تواند در شرایط مناسب در ترجمه استثناهای Persistence نیز نقش داشته باشد.

نمونه کد و مقایسه

نمونه کد / سه لایه با Annotation مناسبJAVA
import org.springframework.stereotype.Component;
import org.springframework.stereotype.Service;
import org.springframework.stereotype.Repository;

@Component
class PaymentValidator {
    boolean isValid(long amount) { return amount > 0; }
}

@Service
class PaymentService { }

@Repository
class PaymentRepository { }
سؤال مرور درس 05 — نمایش پاسخ

سؤال: برای Validator، Service و Repository چه Annotationهایی مناسب‌اند؟

پاسخ: به‌ترتیب @Component، @Service و @Repository؛ گزینه C.

درس 06 · فصل نهم

ساخت REST API با @RestController و @GetMapping

مفهوم و نکات کلیدی

@RestController برای مدیریت Endpointهایی مناسب است که نتیجه را در HTTP Response Body می‌نویسند. @RequestMapping مسیر پایه و @GetMapping متد GET را تعیین می‌کند. این مدل با [ApiController]، [Route] و [HttpGet] در ASP.NET Core قابل مقایسه است. برای تبدیل اشیا به JSON باید Message Converter مناسب، معمولاً Jackson، در دسترس باشد.

نمونه کد و مقایسه

نمونه کد / REST API سادهJAVA
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/payments")
public class PaymentController {
    @GetMapping
    public String getPayments() {
        return "Payment API";
    }
}
نمونه کد / پاسخ DTO در SpringJAVA
record PaymentResponse(long id, int amount, String status) {}

// With Jackson available:
// return new PaymentResponse(1001, 50000, "Success");
نمونه کد / مقایسه Controller در دات‌نتCSHARP
[ApiController]
[Route("api/payments")]
public class PaymentsController : ControllerBase {
    [HttpGet]
    public IActionResult Get() => Ok("Payment API");
}
سؤال مرور درس 06 — نمایش پاسخ

سؤال: چه ترکیب Annotation برای GET /api/payments صحیح است؟

پاسخ: @RestController و @RequestMapping روی کلاس، @GetMapping روی متد؛ گزینه D.

درس 07 · فصل نهم

دریافت ورودی با @PathVariable و @RequestParam و @RequestBody

مفهوم و نکات کلیدی

@PathVariable مقدار را از بخش متغیر مسیر URL می‌خواند؛ @RequestParam برای Query Parameter است؛ @RequestBody محتوای Body را با کمک مبدل مناسب به Object نگاشت می‌کند. در ASP.NET Core به‌ترتیب مشابه [FromRoute]، [FromQuery] و [FromBody] هستند. @RequestBody به‌تنهایی Bean Validation را فعال نمی‌کند.

نمونه کد و مقایسه

نمونه کد / سه روش دریافت ورودیJAVA
import org.springframework.web.bind.annotation.*;

record CreatePaymentRequest(long customerId, int amount) {}

@RestController
@RequestMapping("/api/payments")
class PaymentController {
    @GetMapping("/{id}")
    public Long get(@PathVariable Long id) { return id; }

    @GetMapping
    public String search(@RequestParam String status) { return status; }

    @PostMapping
    public String create(@RequestBody CreatePaymentRequest req) {
        return "Amount: " + req.amount();
    }
}
نمونه کد / نمونه درخواستHTTP
POST /api/payments
Content-Type: application/json

{"customerId":100,"amount":50000}
سؤال مرور درس 07 — نمایش پاسخ

سؤال: کار @RequestBody چیست؟

پاسخ: تبدیل Body درخواست به Object جاوا با Converter مناسب؛ گزینه C.

درس 08 · فصل نهم

تنظیمات با application.properties و application.yml

مفهوم و نکات کلیدی

Spring Boot تنظیمات را از قالب Properties یا YAML می‌خواند. @Value یک مقدار مشخص را تزریق می‌کند و @ConfigurationProperties برای تنظیمات گروهی مفید است. با application-prod.yml و فعال‌کردن Spring Profile، تنظیمات آن محیط بارگذاری می‌شوند. Spring Profile زمان اجرا را نباید با Maven Profile زمان Build اشتباه گرفت. اسرار را در Git نگهداری نکنید.

نمونه کد و مقایسه

نمونه کد / application.ymlYAML
server:
  port: 8081
payment:
  max-amount: 5000000
  currency: IRR
نمونه کد / application-prod.ymlYAML
server:
  port: 9090
نمونه کد / خواندن پیکربندی در ServiceJAVA
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

@Service
class PaymentService {
    private final long maxAmount;
    public PaymentService(@Value("${payment.max-amount}") long maxAmount) {
        this.maxAmount = maxAmount;
    }
    public boolean isValid(long amount) {
        return amount > 0 && amount <= maxAmount;
    }
}
نمونه کد / فعال‌کردن تنظیمات ProductionBASH
java -jar payment-service.jar --spring.profiles.active=prod
سؤال مرور درس 08 — نمایش پاسخ

سؤال: با فعال‌بودن prod و application-prod.yml دارای server.port=9090، پورت چیست؟

پاسخ: با فرض نبود تنظیم بازنویس دیگر، 9090؛ گزینه B.

درس 09 · فصل نهم

مدیریت Exception با @RestControllerAdvice و @ExceptionHandler

مفهوم و نکات کلیدی

برای مدیریت مرکزی استثناهای Controller می‌توان از @RestControllerAdvice و @ExceptionHandler استفاده کرد. خطای معتبرسازی دامنه مانند مبلغ منفی می‌تواند به 400 Bad Request نگاشت شود؛ خطاهای پیش‌بینی‌نشده را نباید همگی 400 کرد یا جزئیات حساسشان را به Client نشان داد. در دات‌نت مفهوم مشابه IExceptionHandler است.

نمونه کد و مقایسه

نمونه کد / Service که Exception تولید می‌کندJAVA
import org.springframework.stereotype.Service;
@Service
class PaymentService {
    public void createPayment(long amount) {
        if (amount <= 0)
            throw new IllegalArgumentException("Payment amount must be positive");
    }
}
نمونه کد / Global REST Exception HandlerJAVA
import org.springframework.http.*;
import org.springframework.web.bind.annotation.*;

record ErrorResponse(String message) {}

@RestControllerAdvice
class GlobalExceptionHandler {
    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<ErrorResponse> handle(IllegalArgumentException ex) {
        return ResponseEntity.status(HttpStatus.BAD_REQUEST)
            .body(new ErrorResponse(ex.getMessage()));
    }
}
سؤال مرور درس 09 — نمایش پاسخ

سؤال: چه ابزاری برای Handler مشترک IllegalArgumentException مناسب است؟

پاسخ: @RestControllerAdvice و @ExceptionHandler؛ گزینه C.

درس 10 · فصل نهم

معماری Controller، Service و Repository در Spring Boot

مفهوم و نکات کلیدی

Controller مسئول قرارداد HTTP، Service مسئول قوانین کسب‌وکار و Repository مسئول ذخیره و بازیابی داده است. Dependencyها را با Constructor Injection تزریق می‌کنیم. نمونه زیر در حافظه ذخیره می‌کند و برای محیط واقعی پرداخت نیست؛ در فصل دهم به JPA و Hibernate می‌رسیم. در Production باید Idempotency، Transaction و Concurrency را نیز بررسی کرد.

نمونه کد و مقایسه

نمونه کد / ساختار پروژهTEXT
src/main/java/com/example/payment/
├── PaymentApplication.java
├── controller/PaymentController.java
├── service/PaymentService.java
├── repository/PaymentRepository.java
└── dto/CreatePaymentRequest.java
نمونه کد / DTO (در فایل CreatePaymentRequest.java)JAVA
package com.example.payment.dto;
public record CreatePaymentRequest(long customerId, long amount) {}
نمونه کد / Repository در حافظه (در فایل PaymentRepository.java)JAVA
package com.example.payment.repository;
import java.util.concurrent.ConcurrentHashMap;
import org.springframework.stereotype.Repository;

@Repository
public class PaymentRepository {
    private final ConcurrentHashMap<Long, Long> payments =
        new ConcurrentHashMap<>();
    public void save(long customerId, long amount) {
        payments.put(customerId, amount);
    }
}
نمونه کد / لایه Service (در فایل PaymentService.java)JAVA
package com.example.payment.service;
import com.example.payment.repository.PaymentRepository;
import org.springframework.stereotype.Service;

@Service
public class PaymentService {
    private final PaymentRepository repository;
    public PaymentService(PaymentRepository repository) {
        this.repository = repository;
    }
    public void createPayment(long customerId, long amount) {
        if (amount <= 0) throw new IllegalArgumentException("Amount must be positive");
        repository.save(customerId, amount);
    }
}
نمونه کد / لایه Controller (در فایل PaymentController.java)JAVA
package com.example.payment.controller;
import com.example.payment.dto.CreatePaymentRequest;
import com.example.payment.service.PaymentService;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/payments")
public class PaymentController {
    private final PaymentService paymentService;
    public PaymentController(PaymentService paymentService) {
        this.paymentService = paymentService;
    }
    @PostMapping
    public ResponseEntity<String> create(@RequestBody CreatePaymentRequest request) {
        paymentService.createPayment(request.customerId(), request.amount());
        return ResponseEntity.ok("Payment created");
    }
}
