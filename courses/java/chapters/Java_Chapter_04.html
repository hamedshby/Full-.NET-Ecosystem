درس 01 · فصل چهارم

Collection Framework و ساختار مجموعه‌ها

توضیح مفهوم و مقایسه با دات‌نت

در Java اینترفیس Collection از Iterable گسترش می‌یابد و اینترفیس‌های List، Set و Queue از آن مشتق می‌شوند. اما Map شاخه‌ای مستقل است. هنگام انتخاب ساختار مناسب، ترتیب، امکان تکرار، نوع دسترسی و پیچیدگی زمانی اهمیت دارد.

عملیاتJava / ویژگی اولC# / ویژگی دوم
ArrayList<E>List<T>لیست ترتیبی با امکان تکرار
HashSet<E>HashSet<T>مقادیر یکتا
HashMap<K,V>Dictionary<K,V>کلید و مقدار
ArrayDeque<E>Queue<T>صف و پشته درون‌حافظه‌ای

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        List<Integer> payments = new ArrayList<>();
        payments.add(1001);
        payments.add(1002);
        payments.add(1001);
        System.out.println(payments.size()); // 3
    }
}

درس 02 · فصل چهارم

List و ArrayList و عملیات پایه

توضیح مفهوم و مقایسه با دات‌نت

در Java، List اینترفیس و ArrayList یک پیاده‌سازی آن است. مشابه IList<T> و List<T> در سی‌شارپ. متد get(index) برای خواندن، set(index,value) برای جایگزینی و add(value) برای افزودن استفاده می‌شود. متد set تعداد عناصر را تغییر نمی‌دهد.

عملیاتJava / ویژگی اولC# / ویژگی دوم
add(100)Add(100)افزودن
get(0)list[0]خواندن
set(0,500)list[0] = 500جایگزینی
remove(0)RemoveAt(0)حذف با اندیس در List<Integer>
size()Countتعداد

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        List<Integer> numbers = new ArrayList<>();
        numbers.add(10);
        numbers.add(20);
        numbers.add(30);
        numbers.set(1, 99);
        System.out.println(numbers.size()); // 3
        System.out.println(numbers.get(1)); // 99
    }
}
سؤال مرور درس 02 — نمایش پاسخ

سؤال: بعد از set(1,99)، خروجی size و get(1) چیست؟

پاسخ: به ترتیب ۳ و ۹۹؛ set عنصر را جایگزین می‌کند.

درس 03 · فصل چهارم

تفاوت ArrayList و LinkedList

توضیح مفهوم و مقایسه با دات‌نت

کلاس ArrayList از آرایه پویا استفاده می‌کند؛ بنابراین خواندن با اندیس در آن O(1) است. کلاس LinkedList فهرست پیوندی دوطرفه است و برای دسترسی به اندیس میانی معمولاً پیمایش O(n) لازم دارد. درج یا حذف در ابتدای LinkedList پس از دسترسی به ابتدا O(1) است. در اغلب کاربردهای عمومی ArrayList انتخاب پیش‌فرض بهتری است.

عملیاتJava / ویژگی اولC# / ویژگی دوم
دسترسی بر اساس اندیسO(1)O(n)
افزودن در انتهاO(1) سرشکنO(1)
درج در ابتدای ساختارO(n)O(1)
حذف در وسط بر اساس اندیسO(n)O(n) با جست‌وجو

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        List<Integer> a = new ArrayList<>();
        List<Integer> b = new LinkedList<>();
        a.add(100); b.add(100);
        System.out.println(a.get(0)); // 100
        System.out.println(b.get(0)); // 100
    }
}
سؤال مرور درس 03 — نمایش پاسخ

سؤال: برای دسترسی مکرر به payments.get(50000) کدام انتخاب بهتر است؟

پاسخ: ArrayList؛ زیرا دسترسی با اندیس O(1) است.

درس 04 · فصل چهارم

HashSet و جلوگیری از مقادیر تکراری

توضیح مفهوم و مقایسه با دات‌نت

در Java، اینترفیس Set اجازه نگهداری مقدار تکراری را نمی‌دهد. HashSet معمولاً عملیات افزودن و جست‌وجو را به‌طور میانگین با پیچیدگی O(1) انجام می‌دهد. ترتیب پیمایش HashSet تضمین نمی‌شود. متد add برای عضو تازه true و برای عضو موجود false برمی‌گرداند.

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Set<String> ids = new HashSet<>();
        System.out.println(ids.add("TX-100")); // true
        System.out.println(ids.add("TX-200")); // true
        System.out.println(ids.add("TX-100")); // false
        System.out.println(ids.size()); // 2
    }
}
سؤال مرور درس 04 — نمایش پاسخ

سؤال: پس از افزودن دوباره TX-100، خروجی add و اندازه مجموعه چیست؟

پاسخ: به‌ترتیب false و ۲. برای جلوگیری از تراکنش تکراری در سرویس توزیع‌شده، HashSet حافظه‌ای به‌تنهایی کافی نیست و به تضمین پایدار مثل Unique Constraint نیاز داریم.

درس 05 · فصل چهارم

HashMap و نگهداری کلید و مقدار

توضیح مفهوم و مقایسه با دات‌نت

در Java، اینترفیس Map<K,V> برای نگهداری زوج کلید و مقدار است و کلاس HashMap یکی از پیاده‌سازی‌های آن است. کلیدها یکتا هستند. برخلاف متد Add در Dictionary سی‌شارپ، put برای کلید موجود مقدار را جایگزین می‌کند. متد get برای کلید ناموجود null می‌دهد؛ البته null می‌تواند خودش یک مقدار ذخیره‌شده باشد.

عملیاتJava / ویژگی اولC# / ویژگی دوم
put(key,value)dict[key] = valueافزودن یا جایگزینی
get(key)dict[key]دریافت (رفتار کلید ناموجود متفاوت است)
containsKey(key)ContainsKey(key)بررسی کلید
size()Countتعداد

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Map<Integer, String> payments = new HashMap<>();
        payments.put(1001, "Pending");
        payments.put(1002, "Success");
        payments.put(1001, "Failed");
        System.out.println(payments.size()); // 2
        System.out.println(payments.get(1001)); // Failed
    }
}
سؤال مرور درس 05 — نمایش پاسخ

سؤال: چرا پس از سه بار put، اندازه Map برابر ۲ است؟

پاسخ: چون کلید ۱۰۰۱ تکراری بوده و مقدار Failed جایگزین Pending شده است.

درس 06 · فصل چهارم

equals و hashCode در مجموعه‌های هش‌محور

توضیح مفهوم و مقایسه با دات‌نت

در Java، عملگر == روی ارجاعات هویت شیء را مقایسه می‌کند. پیاده‌سازی پیش‌فرض equals() در Object نیز برابری هویت را بررسی می‌کند. اگر اشیای دارای شناسه یکسان باید برابر باشند، equals و hashCode را به‌صورت هماهنگ بازنویسی کن. اشیای برابر باید هش برابر داشته باشند؛ اما هش برابر لزوماً به معنای برابر بودن اشیا نیست.

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
class Payment {
    private final int id;
    Payment(int id) { this.id = id; }
    @Override public boolean equals(Object obj) {
        if (this == obj) return true;
        if (!(obj instanceof Payment other)) return false;
        return id == other.id;
    }
    @Override public int hashCode() {
        return Integer.hashCode(id);
    }
}
public class Main {
    public static void main(String[] args) {
        Set<Payment> payments = new HashSet<>();
        payments.add(new Payment(1001));
        payments.add(new Payment(1001));
        System.out.println(payments.size()); // 1
    }
}
سؤال مرور درس 06 — نمایش پاسخ

سؤال: اگر equals و hashCode را Override نکنیم، دو شیء new Payment(1001) در HashSet چند عنصر خواهند بود؟

پاسخ: دو عنصر؛ چون به‌طور پیش‌فرض برابری مبتنی بر هویت شیء است.

درس 07 · فصل چهارم

Comparable و Comparator برای مرتب‌سازی

توضیح مفهوم و مقایسه با دات‌نت

اینترفیس Comparable<T> ترتیب طبیعی را با متد compareTo تعیین می‌کند؛ مشابه IComparable<T> در سی‌شارپ. اینترفیس Comparator<T> ترتیب سفارشی را فراهم می‌کند؛ مشابه IComparer<T>. خروجی مقایسه باید در صورت کمتر بودن منفی، برابر بودن صفر و بیشتر بودن مثبت باشد.

عملیاتJava / ویژگی اولC# / ویژگی دوم
Comparable<T>IComparable<T>ترتیب طبیعی
Comparator<T>IComparer<T>ترتیب سفارشی

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        List<Integer> amounts =
            new ArrayList<>(List.of(300, 100, 200));
        amounts.sort(Comparator.reverseOrder());
        System.out.println(amounts); // [300, 200, 100]
    }
}
سؤال مرور درس 07 — نمایش پاسخ

سؤال: Comparator.reverseOrder() چه ترتیبی ایجاد می‌کند؟

پاسخ: مرتب‌سازی نزولی؛ خروجی مثال [300, 200, 100] است.

درس 08 · فصل چهارم

Generics و Type Erasure

توضیح مفهوم و مقایسه با دات‌نت

در Java می‌توانیم کلاس عمومی Response<T> تعریف کنیم؛ اما بخش عمده اطلاعات نوع Generic هنگام کامپایل با Type Erasure حذف می‌شود. بنابراین getClass() دو نمونه ArrayList با پارامترهای نوع متفاوت، کلاس یکسانی برمی‌گرداند. همچنین پارامترهای Generic نمی‌توانند primitive باشند: به‌جای List<int> از List<Integer> استفاده می‌کنیم.

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
class Response<T> {
    private final T data;
    Response(T data) { this.data = data; }
    T getData() { return data; }
}
public class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>();
        List<Integer> numbers = new ArrayList<>();
        System.out.println(
            names.getClass() == numbers.getClass()); // true
        Response<String> r = new Response<>("Success");
        System.out.println(r.getData());
    }
}
سؤال مرور درس 08 — نمایش پاسخ

سؤال: چرا names.getClass() == numbers.getClass() خروجی true دارد؟

پاسخ: به دلیل Type Erasure و اینکه هر دو نمونه از کلاس ArrayList هستند.

درس 09 · فصل چهارم

Generic Bounds و Wildcards

توضیح مفهوم و مقایسه با دات‌نت

در Java عبارت <T extends Payment> نوع Generic را به Payment یا زیرنوع آن محدود می‌کند. برای نوع‌های ناشناخته از Wildcard ? استفاده می‌کنیم. عبارت ? extends Number بیشتر برای خواندن به‌عنوان Number و ? super Integer برای افزودن Integer مناسب است. قانون معروف PECS یعنی Producer Extends، Consumer Super.

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        List<? extends Number> source =
            new ArrayList<Integer>();
        // source.add(100); // Compile Error

        List<? super Integer> target =
            new ArrayList<Number>();
        target.add(100); // OK
        System.out.println(target.get(0)); // 100
    }
}
سؤال مرور درس 09 — نمایش پاسخ

سؤال: چرا source.add(100) برای List<? extends Number> کامپایل نمی‌شود؟

پاسخ: زیرا نوع دقیق پارامتر لیست ناشناخته است؛ شاید لیست Double یا زیرنوع دیگری از Number باشد.

درس 10 · فصل چهارم

Queue و Deque و الگوی FIFO

توضیح مفهوم و مقایسه با دات‌نت

اینترفیس Queue<E> برای صف است و ArrayDeque پیاده‌سازی مناسبی برای صف و پشته در حافظه است. در صف FIFO، عنصر اول زودتر خارج می‌شود. متد offer عنصر را اضافه، poll آن را حذف و برمی‌گرداند و peek فقط مشاهده می‌کند. در صف خالی، poll و peek مقدار null می‌دهند؛ remove و element استثنا پرتاب می‌کنند. Deque افزودن و حذف از هر دو سر را پشتیبانی می‌کند.

عملیاتJava / ویژگی اولC# / ویژگی دوم
poll()nullبرداشتن ابتدای صف
remove()NoSuchElementExceptionبرداشتن ابتدای صف
peek()nullمشاهده ابتدای صف
element()NoSuchElementExceptionمشاهده ابتدای صف

مثال عملی

نمونه کد / JavaJAVA
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(100);
        queue.offer(200);
        queue.offer(300);
        System.out.println(queue.poll()); // 100
        System.out.println(queue.peek()); // 200
        System.out.println(queue.size()); // 2
    }
}

پاسخ: به ترتیب ۱۰۰، ۲۰۰ و ۲؛ چون peek عضو را حذف نمی‌کند.
