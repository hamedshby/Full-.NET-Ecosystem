درس 01 · فصل اول

تفاوت JDK، JRE و JVM

توضیح مفهوم و مقایسه با دات‌نت

در جاوا نیز مثل دات‌نت کد منبع معمولاً ابتدا به یک کد میانی تبدیل می‌شود. ابزار javac فایل .java را به Bytecode داخل فایل .class تبدیل می‌کند و JVM آن را اجرا می‌کند.

مفهومکاربردمعادل تقریبی در دات‌نت
JDKکیت توسعه شامل کامپایلر و ابزارهای اجرایی.NET SDK
JREمحیط اجرای کلاسیک: JVM و کتابخانه‌های اجرا.NET Runtime
JVMماشین مجازی اجرای Bytecode و مدیریت حافظهCLR

در توزیع‌های مدرن، نصب JDK راه ساده‌ای برای داشتن ابزارهای توسعه و اجرای جاواست و معمولاً دیگر لازم نیست بسته JRE جداگانه نصب کنی.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
javac Hello.java
java Hello
سؤال مرور درس 01 — نمایش پاسخ

سؤال: برای اجرای یک فایل کلاس از پیش کامپایل‌شده، آیا کامپایلر javac الزامی است؟

پاسخ: خیر؛ JVM سازگار همراه کتابخانه‌ها و وابستگی‌های لازم کافی است.

درس 02 · فصل اول

مقایسه اجرای Java و .NET

توضیح مفهوم و مقایسه با دات‌نت

کامپایلر جاوا معمولاً Bytecode می‌سازد؛ کامپایلر #C معمولاً IL تولید می‌کند. هر دو Runtime قادرند بخشی از کد میانی را هنگام اجرا به کد ماشین کامپایل کنند.

جاوادات‌نت
Payment.java → javac → Payment.classPayment.cs → C# compiler → IL
JVM / JITCLR / JIT

این مسیر حالت متداول است، نه تنها مسیر ممکن؛ برای هر دو اکوسیستم شیوه‌های دیگری نظیر AOT نیز وجود دارد.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
javac Payment.java
java Payment
سؤال مرور درس 02 — نمایش پاسخ

سؤال: کامپایلر javac در حالت معمول چه خروجی می‌دهد؟

پاسخ: Bytecode، معمولاً در فایل‌های .class.

درس 03 · فصل اول

نصب JDK و IntelliJ IDEA

توضیح مفهوم و مقایسه با دات‌نت

برای توسعه جاوا به JDK و یک محیط توسعه نیاز داری. می‌توانی از توزیع Eclipse Temurin و محیط IntelliJ IDEA استفاده کنی.

  1. یک نسخه LTS از JDK نصب کن.
  2. در صورت نیاز گزینه‌های PATH و JAVA_HOME را تنظیم کن.
  3. ترمینال جدید باز کن و نسخه Java و کامپایلر را بررسی کن.
  4. IntelliJ IDEA را نصب کن و هنگام ساخت پروژه JDK را انتخاب کن.

آدرس دریافت: adoptium.net و jetbrains.com/idea.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
java -version
javac -version
# در PowerShell:
echo $env:JAVA_HOME
سؤال مرور درس 03 — نمایش پاسخ

سؤال: برای بررسی اینکه کامپایلر در مسیر فرمان قابل اجراست چه دستوری می‌زنیم؟

پاسخ: javac -version

درس 04 · فصل اول

ساخت اولین برنامه Java

توضیح مفهوم و مقایسه با دات‌نت

برای شروع، فایلی به نام Main.java بساز. اگر کلاس بالادستی public باشد، نام فایل منبع باید با نام کلاس یکسان باشد.

متد System.out.println معادل تقریبی Console.WriteLine در دات‌نت است.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}

// CMD / Terminal:
// javac Main.java
// java Main
// Output: Hello Java
سؤال مرور درس 04 — نمایش پاسخ

سؤال: برای اجرای کلاس Main که قبلاً کامپایل شده، چه دستوری لازم است؟

پاسخ: java Main (بدون پسوند .class). نکته: java Main.java نیز در نسخه‌های مدرن می‌تواند سورس را مستقیماً اجرا کند.

درس 05 · فصل اول

ساختار کلاس و متد main

توضیح مفهوم و مقایسه با دات‌نت

در ساختار کلاسیک، متد public static void main(String[] args) نقطه شروع برنامه است. static یعنی برای صدا زدن متد نیاز به نمونه کلاس نداریم و String[] args آرگومان‌های خط فرمان را می‌گیرد.

یک متد نمونه‌ای (instance method) را نمی‌توان مستقیماً از زمینه static صدا زد؛ باید نمونه‌ای از کلاس ساخت. در نسخه‌های جدیدتر جاوا شکل‌های ساده‌تری از نقطه ورود نیز پشتیبانی می‌شود، ولی در پروژه‌های موجود ساختار کلاسیک رایج است.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
public class Payment {
    public static void main(String[] args) {
        Payment payment = new Payment();
        payment.process();
    }

    public void process() {
        System.out.println("Processing payment...");
    }
}
سؤال مرور درس 05 — نمایش پاسخ

سؤال: چرا فراخوانی مستقیم process() از main در مثال بالا (بدون ساخت شیء) خطای کامپایل می‌دهد؟

پاسخ: چون process متد نمونه‌ای است و main متد static.

درس 06 · فصل اول

متغیرها و انواع Primitive

توضیح مفهوم و مقایسه با دات‌نت

جاوا هشت نوع اولیه دارد: byte، short، int، long، float، double، char و boolean.

Javaنکته مهم نسبت به #C
booleanمعادل bool
byteعلامت‌دار (۱۲۸- تا ۱۲۷)، شبیه sbyte
long۶۴ بیتی؛ پسوند عدد صحیح بزرگ L
double / floatممیز شناور دودویی؛ برای مقدار پولی دقیق مناسب نیستند

لیترال عدد صحیح بدون پسوند، در حالت متداول، باید در محدوده int جا شود؛ اگر بزرگ‌تر است پسوند L لازم است.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
int transactionId = 1001;
long customerId = 9000000000L;
boolean successful = true;

// Compile Error: integer number too large
// long amount = 9000000000;
سؤال مرور درس 06 — نمایش پاسخ

سؤال: آیا long amount = 3000000000L کامپایل می‌شود؟

پاسخ: بله؛ پسوند L باعث می‌شود لیترال long باشد.

درس 07 · فصل اول

Primitive و Reference Type

توضیح مفهوم و مقایسه با دات‌نت

در مورد مقدار اولیه مانند int، انتساب مقدار را کپی می‌کند. در مورد اشیا، انتساب مقدار Reference را کپی می‌کند؛ بنابراین دو متغیر می‌توانند به یک شیء مشترک اشاره کنند.

جاوا پارامترهای متد را همیشه با روش pass-by-value می‌فرستد، حتی زمانی که آن مقدار یک Reference است.

برخلاف #C، جاوا نوع struct دلخواه با رفتار Value Type مشابه #C ندارد؛ String و آرایه‌ها نیز از انواع ارجاعی‌اند.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
class Payment {
    int amount;
}

Payment p1 = new Payment();
p1.amount = 100;
Payment p2 = p1;
p2.amount = 200;
System.out.println(p1.amount); // 200
سؤال مرور درس 07 — نمایش پاسخ

سؤال: چرا تغییر p2.amount در مثال، p1.amount را هم تغییر داده است؟

پاسخ: چون هر دو Reference به یک شیء مشترک اشاره می‌کنند.

درس 08 · فصل اول

عملگرها، if و switch

توضیح مفهوم و مقایسه با دات‌نت

ساختار if / else و عملگرهای معمول در جاوا بسیار شبیه #C است. در جاوای مدرن می‌توانیم از switch expression با پیکان -> استفاده کنیم و نتیجه را در متغیر قرار دهیم.

در این فرم، برخلاف switch قدیمی با caseهای دونقطه‌دار، نیازی به break نیست و عبور خودکار به شاخه بعد رخ نمی‌دهد.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
String status = "SUCCESS";
String message = switch (status) {
    case "SUCCESS" -> "Payment completed";
    case "FAILED" -> "Payment failed";
    case "PENDING" -> "Payment pending";
    default -> "Unknown status";
};
System.out.println(message);
سؤال مرور درس 08 — نمایش پاسخ

سؤال: اگر status برابر FAILED باشد، نتیجه switch چیست؟

پاسخ: Payment failed

درس 09 · فصل اول

حلقه‌های for و while و Enhanced for

توضیح مفهوم و مقایسه با دات‌نت

حلقه‌های for و while تقریباً هم‌شکل #C هستند. معادل حلقه foreach در جاوا معمولاً for (int value : values) است.

در Enhanced for روی یک آرایه از اعداد اولیه، مقدار هر عنصر در متغیر محلی کپی می‌شود. پس تغییر متغیر حلقه، خانه اصلی آرایه را تغییر نمی‌دهد. برای تغییر عنصر باید با اندیس به آرایه دسترسی پیدا کرد.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
int[] amounts = {100, 200, 300};
for (int amount : amounts) {
    amount *= 2;
}
System.out.println(amounts[0]); // 100

for (int i = 0; i < amounts.length; i++) {
    amounts[i] *= 2;
}
System.out.println(amounts[0]); // 200
سؤال مرور درس 09 — نمایش پاسخ

سؤال: اگر داخل Enhanced for بنویسیم number += 5، خانه اصلی آرایه int تغییر می‌کند؟

پاسخ: خیر؛ متغیر محلی حلقه تغییر می‌کند نه خانه آرایه.

درس 10 · فصل اول

String، StringBuilder و مقایسه رشته‌ها

توضیح مفهوم و مقایسه با دات‌نت

مانند #C، شیء String در جاوا تغییرناپذیر (immutable) است. اتصال رشته‌ها می‌تواند رشته تازه ایجاد کند. برای اتصال‌های زیاد و تکراری، StringBuilder مناسب است.

تفاوت مهم: عملگر == روی دو Reference، هویت مرجع را مقایسه می‌کند، اما String.equals() محتوای رشته‌ها را. در #C عملگر == برای string مقایسه محتوایی انجام می‌دهد.

مثال عملی

نمونه کد / دستورJAVA / TERMINAL
String a = new String("Java");
String b = new String("Java");
System.out.println(a == b);      // false
System.out.println(a.equals(b)); // true

StringBuilder builder = new StringBuilder();
builder.append("Payment").append(" Success");
System.out.println(builder.toString());
سؤال مرور درس 10 — نمایش پاسخ

سؤال: در دو رشته ساخته‌شده با new String("Java") نتیجه == و equals به‌ترتیب چیست؟

پاسخ: false و سپس true.
