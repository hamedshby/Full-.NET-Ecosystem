Following along on other platforms

Windows

در Windows 10 و نسخه‌های بعدی می‌توانید از Windows Subsystem for Linux (WSL) برای اجرای محیط Linux در خود Windows استفاده کنید. این محیط برای تمرین Bash و ابزارهای متداول مناسب است، هرچند دسکتاپ کامل Linux نیست.

macOS

ترمینال macOS به‌طور پیش‌فرض از Zsh استفاده می‌کند؛ این shell به Bash شباهت دارد اما یکی نیست. macOS هم Linux نیست. برای دنبال‌کردن بخش‌های وابسته به Linux، ماشین مجازی گزینهٔ مناسب‌تری است. هنگام انتخاب image ماشین مجازی، معماری پردازندهٔ Intel یا Apple silicon را در نظر بگیرید.

میزبان Linux راه‌دور

می‌توانید با SSH به یک میزبان Linux وصل شوید و بیشتر دستورهای خط فرمان را تمرین کنید، اما راه‌اندازی آن خارج از محدودهٔ این دوره است و بخش‌های مربوط به رابط گرافیکی را پوشش نمی‌دهد.
