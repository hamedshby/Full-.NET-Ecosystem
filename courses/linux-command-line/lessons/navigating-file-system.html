Navigating the file system

هر پنجرهٔ ترمینال برای اجرای فرمان‌ها یک «پوشهٔ کاری فعلی» دارد. دستور pwd مسیر آن را نشان می‌دهد، ls محتویاتش را فهرست می‌کند و cd آن را تغییر می‌دهد.

یک رفت‌وبرگشت کوتاه

Bash
cd ~
pwd
cd /etc
ls
cd ..
pwd
cd -
pwd
  1. cd ~ به پوشهٔ شخصی می‌رود. pwd مسیر واقعی آن را چاپ می‌کند.
  2. cd /etc پوشه را تغییر می‌دهد. حالا ls محتویات /etc را فهرست می‌کند.
  3. cd .. یک سطح بالا می‌رود؛ از /etc به / می‌رسید. cd - به پوشهٔ قبلی، یعنی /etc، برمی‌گردد.

اگر نام پوشه فاصله دارد، کل مسیر را در نقل‌قول بگذارید؛ مثل cd "my notes". این مثال وقتی کار می‌کند که پوشهٔ my notes در مسیر فعلی وجود داشته باشد.
