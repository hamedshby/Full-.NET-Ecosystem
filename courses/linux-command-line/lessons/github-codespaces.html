Using GitHub Codespaces with this course

GitHub Codespaces یک محیط توسعهٔ ابری است که از مرورگر باز می‌شود. هرچند برای برنامه‌نویسی طراحی شده، ترمینال آن برای تمرین خط فرمان Linux مناسب است و برای شروع به رایانهٔ Linux جداگانه نیاز ندارید.

مراحل شروع

  1. صفحهٔ مخزن فایل‌های تمرینی دوره را باز کنید و آن را به حساب خود Fork کنید.
  2. از نسخهٔ خودتان، منوی Code را باز کنید و Create Codespace on Main را انتخاب کنید.
  3. پس از آماده‌شدن محیط، از منوی بالا Terminal → New Terminal را باز کنید.
  4. در ترمینال به پوشهٔ تمرین بروید و دستورهای دوره را اجرا کنید.
⚠️
Codespaces یک Linux container ابری است، نه Ubuntu Desktop محلی. مسیر home، سطح دسترسی کاربر و prompt ممکن است متفاوت باشد و اجرای برنامه‌های گرافیکی محیط مدرس در آن ممکن نیست.

فایل‌های تمرینی را می‌توانید از پنل فایل‌ها باز کنید. تغییراتی که در محیط ایجاد می‌کنید برای ذخیرهٔ دائمی باید به fork خودتان commit شوند.
