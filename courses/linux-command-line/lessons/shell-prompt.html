دوآپس/2. Command-Line Basics
یادداشت دوره
اجرای دستور

Write commands in a shell at the prompt

برای کار با shell معمولاً یک برنامهٔ Terminal را باز می‌کنیم. Terminal پنجره‌ای است که shell را اجرا می‌کند. خطی که shell نشان می‌دهد Prompt نام دارد و محل واردکردن دستور است. ممکن است نام کاربر، رایانه و پوشهٔ جاری را هم نشان دهد؛ علامت ~ معمولاً به پوشهٔ home اشاره می‌کند.

چند دستور برای شروع

Bash
ls
ls -l
clear

ls نام فایل‌ها و پوشه‌های مسیر جاری را نشان می‌دهد. افزودن -l جزئیات بیشتری می‌دهد. گزینه فقط همان اجرای دستور را تغییر می‌دهد؛ اجرای دوبارهٔ ls بدون گزینه رفتار پیش‌فرض را دارد.

اگر دستور اجرا نشد

اگر نام دستور اشتباه باشد یا برنامه نصب نباشد، shell معمولاً پیام command not found می‌دهد. در خط فرمان، بزرگی و کوچکی حروف و فاصله‌ها را دقیق وارد کنید. خطای تایپی در نام فرمان معمولاً فقط اجرا نمی‌شود، اما گزینهٔ اشتباه ممکن است نتیجهٔ واقعی داشته باشد؛ پیش از اجرای دستورهای ناآشنا آن‌ها را بررسی کنید.

📌
بعضی دستورها برنامه‌های مستقل‌اند و بعضی دیگر دستورهای داخلی Bash هستند. ابزارهای GNU Coreutils هم مجموعه‌ای از فرمان‌های پایهٔ رایج Linux را فراهم می‌کنند.
