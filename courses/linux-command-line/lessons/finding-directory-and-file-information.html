Finding directory and file information

وقتی ls /etc را اجرا می‌کنید، نام موارد داخل پوشه را می‌بینید. برای دیدن اطلاعات خود پوشه، مثل زمان آخرین تغییر یا مالک آن، باید به ls بگویید محتویات پوشه را باز نکند.

Bash
ls -l /etc
ls -ld /etc
ls -lh /etc/hosts
  • ls -l /etc جزئیات موارد داخل /etc را نشان می‌دهد.
  • ls -ld /etc با گزینهٔ -d جزئیات خود پوشه را در یک سطر نشان می‌دهد.
  • ls -lh /etc/hosts جزئیات یک فایل را می‌دهد. -h برای اندازه‌های بزرگ‌تر از واحدهای خوانایی مثل K استفاده می‌کند.

چطور یک سطر را بخوانیم؟

این یک نمونه از خروجی است؛ اندازه، نام مالک و تاریخ ممکن است در سیستم شما متفاوت باشند:

نمونهٔ خروجی
-rw-r--r-- 1 root root 221 Nov 25 09:30 /etc/hosts

نویسهٔ اول نوع را نشان می‌دهد: - برای فایل معمولی و d برای پوشه. نویسه‌های بعدی مجوزهای دسترسی‌اند؛ یعنی چه کسانی می‌توانند فایل را بخوانند، تغییر دهند یا اجرا کنند. در این مثال مالک root، اندازه ۲۲۱ بایت و مسیر /etc/hosts است.
