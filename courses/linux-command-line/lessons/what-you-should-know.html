What you should know

برای شروع، کافی است با استفادهٔ معمول از رایانه آشنا باشید: فایل و پوشه را بشناسید و بدانید چطور یک برنامه را اجرا می‌کنند. آشنایی با Windows یا macOS هم کمک می‌کند چون می‌توانید بعضی کارهای محیط گرافیکی را با دستورهای خط فرمان مقایسه کنید.

یک محیط برای تمرین انتخاب کنید

مدرس از Ubuntu Desktop استفاده می‌کند. اگر رایانهٔ Linux ندارید، می‌توانید GitHub Codespaces را در مرورگر باز کنید، یک Linux مجازی بسازید، یا از گزینه‌های دیگر متناسب با سیستم‌عاملتان استفاده کنید. لازم نیست همهٔ روش‌ها را راه‌اندازی کنید؛ یک گزینه را انتخاب کنید که روی رایانهٔ شما قابل‌استفاده است.

💡
فایل‌های تمرینی و فهرست دستورهای دوره در GitHub قرار دارند. پس از آماده‌شدن محیط، فایل‌ها را دریافت کنید. اگر دستورها را دستی تایپ می‌کنید، فاصله‌گذاری و املای دقیق مهم است.

در ویدیوهای فصل آماده‌سازی، روش‌های مختلف را ببینید و گزینه‌ای را انتخاب کنید که با امکانات و تجربهٔ شما جور است.
