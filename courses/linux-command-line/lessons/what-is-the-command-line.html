What is the command line?

در رابط گرافیکی، با پنجره‌ها، دکمه‌ها و منوها کار می‌کنیم. در رابط خط فرمان، دستورها را به شکل متن می‌نویسیم و خروجی را نیز متنی می‌بینیم. این روش برای کار با ابزارهای توسعه، تحلیل داده و مدیریت سیستم کاربرد دارد؛ به‌ویژه وقتی برنامه روی سرور یا دستگاهی بدون رابط گرافیکی اجرا می‌شود.

Shell و Bash

برنامه‌ای که متن دستور را می‌خواند و اجرا می‌کند Shell یا مفسر خط فرمان نام دارد. در این دوره از Bash استفاده می‌شود؛ یکی از shellهای پرکاربرد در Linux. Bash در بیشتر توزیع‌های رایج Linux موجود است و در WSL هم می‌توان از آن استفاده کرد. در macOS ممکن است نیاز باشد آن را جداگانه اجرا کنید، چون shell پیش‌فرض آن Zsh است.

✅
خط فرمان جایگزین همهٔ ابزارهای گرافیکی نیست؛ برای بسیاری از کارها مثل ویرایش تصویر، رابط گرافیکی مناسب‌تر است. خط فرمان راهی مستقیم برای کنترل برنامه‌هایی است که از طریق متن کار می‌کنند.
