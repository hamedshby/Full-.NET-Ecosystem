The Linux file system

دستور ls / را اجرا کنید. فهرستی از پوشه‌های بالاترین سطح Linux می‌بینید. آن سطح «ریشهٔ سیستم فایل» است و با / نشان داده می‌شود. فایل‌ها و پوشه‌ها مثل شاخه‌های یک درخت از همین نقطه در دسترس‌اند.

پوشه‌هایی که زیاد می‌بینید

  • /home: محل معمول پوشهٔ شخصی کاربران عادی، مانند /home/sara.
  • /etc: تنظیمات سیستم و بسیاری از برنامه‌ها؛ برای نمونه /etc/hosts.
  • /var: داده‌هایی که در زمان کار سیستم تغییر می‌کنند؛ برای نمونه گزارش‌های ثبت‌شده در /var/log.
  • /tmp: محل فایل‌های موقت. برای نگهداری دائمی فایل‌ها روی این پوشه حساب نکنید.
  • /root: نام رایج پوشهٔ شخصی کاربر مدیر سیستم (root). ریشهٔ درخت همان / است.

حالا ls /etc را اجرا کنید. این بار به جای کل ریشه فقط محتویات یک پوشه را می‌بینید. نام‌ها ممکن است بین توزیع‌های Linux متفاوت باشند.
