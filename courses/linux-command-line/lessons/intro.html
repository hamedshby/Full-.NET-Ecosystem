Learning Linux command line

کار با محیط خط فرمان در ابتدا ممکن است ناآشنا به نظر برسد، چون خبری از پنجره‌ها و دکمه‌های رابط گرافیکی نیست. با شناخت روش کار این محیط، می‌توان دید که برای اجرای دستورها و انجام کارهای تکراری، ابزار قدرتمند و کارآمدی است.

در این دوره با خط فرمان Linux و Bash آشنا می‌شوید. مسیر از شناخت اجزای خط فرمان آغاز می‌شود و به کار با فایل‌ها و پوشه‌ها، مجوزهای دسترسی، دستورهای رایج، اتصال دستورها با Pipe و انجام کارهای پیچیده‌تر می‌رسد.

🎯
هدف این دوره ساختن پایه‌ای برای کار با Bash است؛ پایه‌ای که بعداً می‌توانید آن را برای مدیریت کاربران، شبکه، برنامه‌نویسی، توسعه یا مدیریت سیستم گسترش دهید.

مسیر پیشنهادی مطالعه

ابتدا پیش‌نیازها و آشنایی کوتاه با Linux را بخوانید، سپس یک محیط تمرین انتخاب کنید. بعد از آماده‌شدن محیط، مبانی خط فرمان و دستورها را به‌ترتیب دنبال کنید.
