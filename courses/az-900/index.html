Domain 1: Describe Cloud Computing

  • Module introduction: Cloud concepts

  • Define cloud computing
  • Describe the shared responsibility model
  • Define cloud models
  • Consumption-based model

۰۲

Domain 1مزایای Cloud

Describe the Benefits of Using Cloud Services

مزایای استفاده از سرویس‌های ابری را از نظر هزینه، مقیاس‌پذیری و دسترس‌پذیری مرور کنید.

  • High Availability
  • Scalability و Elasticity
  • هزینهٔ مصرفی
۰۳

Domain 1مدل‌های سرویس

Describe Cloud Service Types

تفاوت مسئولیت‌ها و سطح مدیریت در مدل‌های اصلی سرویس ابری را مشخص کنید.

  • IaaS
  • PaaS
  • SaaS
۰۴

Domain 2معماری Azure

Describe Azure Architecture and Services

با ساختار کلی Azure و اجزایی که سرویس‌های ابری را در دسترس قرار می‌دهند آشنا شوید.

  • ساختار Azure
  • دسته‌بندی سرویس‌ها
  • مفاهیم معماری ابری
۰۵

Domain 2اجزای اصلی

Describe the Core Architectural Components of Azure

اجزای پایه‌ای سازمان‌دهی منابع Azure و رابطهٔ میان آن‌ها را یاد بگیرید.

  • Region و Availability Zone
  • Subscription
  • Resource Group
۰۶

Domain 2Compute و Network

Describe Azure Compute and Networking Services

سرویس‌های اجرای برنامه و اتصال منابع در Azure را مرور کنید.

  • Virtual Machines
  • Containers و Azure Functions
  • Virtual Network
۰۷

Domain 2ذخیره‌سازی

Describe Azure Storage Services

گزینه‌های ذخیره‌سازی داده و انتقال فایل در سرویس‌های Azure را بشناسید.

  • Blob Storage
  • Disk و File Storage
  • Storage Tiers و Redundancy
۰۸

Domain 2هویت و امنیت

Describe Azure Identity, Access, and Security

هویت‌ها، دسترسی‌ها و لایه‌های محافظت از منابع Azure را مرور کنید.

  • Microsoft Entra ID
  • Authentication و Authorization
  • MFA و Conditional Access
۰۹

Domain 3مدیریت و حاکمیت

Describe Azure Management and Governance

ابزارهای مدیریت چرخهٔ عمر منابع و اعمال سیاست‌های سازمانی را بشناسید.

  • Azure Policy
  • Resource Locks
  • مدیریت منابع
۱۰

Domain 3مدیریت هزینه

Describe Cost Management in Azure

هزینهٔ سرویس‌ها را برآورد، پایش و با ابزارهای Azure مدیریت کنید.

  • Pricing Calculator
  • Total Cost of Ownership
  • Cost Management
۱۱

Domain 3Governance

Describe Features and Tools for Governance and Compliance

ابزارها و قابلیت‌هایی را بشناسید که انطباق و حاکمیت منابع را پشتیبانی می‌کنند.

  • Azure Policy
  • Microsoft Purview
  • Compliance و Audit
۱۲

Domain 3مدیریت منابع

Describe Features and Tools for Managing and Deploying Resources

راه‌های مدیریت و استقرار منابع را از Portal تا ابزارهای خط فرمان و قالب‌های زیرساخت مقایسه کنید.

  • Azure Portal و Cloud Shell
  • Azure CLI و PowerShell
  • ARM Templates

Domain 3پایش

Describe Monitoring Tools

ابزارهای مشاهدهٔ سلامت، رخدادها و وضعیت سرویس‌های Azure را مرور کنید.

  • Azure Monitor
  • Service Health
  • Advisor
