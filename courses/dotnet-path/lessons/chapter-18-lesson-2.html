18.2 — Program to an Interface

📅 به‌روزرسانی: ۱۴۰۵/۰۶/۱۵
⏱️ زمان مطالعه: ۱۲ دقیقه
👤 تیم فنی

Program to an Interface, not an Implementation یعنی Consumer تا جای ممکن به Contract مورد نیازش وابسته باشد، نه به جزئیات Concrete Implementation.

💡
منظور از Interface در این اصل فقط keywordِ interface در C# نیست؛ منظور وابستگی به یک Abstraction یا Contract پایدار است.

وابستگی مستقیم به Implementation

C#
public class PaymentService
{
    private readonly BankAGateway _gateway;

    public PaymentService()
    {
        _gateway = new BankAGateway();
    }
}

PaymentService بانک خاص را می‌شناسد و خودش آن را می‌سازد.

طراحی بر اساس Contract

C#
public interface IPaymentGateway
{
    Task<PaymentResult> PayAsync(
        PaymentRequest request,
        CancellationToken cancellationToken);
}

public class PaymentService
{
    private readonly IPaymentGateway _gateway;

    public PaymentService(
        IPaymentGateway gateway)
    {
        _gateway = gateway;
    }
}

Implementationهای مختلف

C#
public class BankAGateway : IPaymentGateway
{
    public Task<PaymentResult> PayAsync(
        PaymentRequest request,
        CancellationToken cancellationToken)
    {
        // Bank A
        throw new NotImplementedException();
    }
}

public class BankBGateway : IPaymentGateway
{
    public Task<PaymentResult> PayAsync(
        PaymentRequest request,
        CancellationToken cancellationToken)
    {
        // Bank B
        throw new NotImplementedException();
    }
}

Consumer فقط می‌داند یک Payment Gateway باید چه کاری انجام دهد؛ جزئیات بانک در Implementation قرار دارد.

ارتباط با Polymorphism و DIP

  • Polymorphism امکان جایگزینی Implementationها را فراهم می‌کند.
  • DIP جهت Dependency را به سمت Abstraction هدایت می‌کند.
  • DI می‌تواند Concrete Implementation را هنگام Runtime تأمین کند.

آیا برای هر Class یک Interface بسازیم؟

⚠️
خیر. Interface بدون Boundary یا Variation واقعی می‌تواند فقط Indirection و Complexity اضافه کند.

این اصل بیشتر در External Services، Infrastructure، Pluginها، Strategyها و Boundaryهایی که تغییرپذیری واقعی دارند ارزشمند است.

نکته مصاحبه‌ای

🎤
Program to an interface means clients depend on the behavior they need rather than unnecessary details of a concrete implementation.

جمع‌بندی

Consumer باید کمترین knowledge لازم را دربارهٔ Provider داشته باشد. Contract مناسب، تغییر Implementation را از Business Logic جدا می‌کند.
