21.7 — Domain Event

📅 به‌روزرسانی: ۱۴۰۵/۰۶/۱۵
⏱️ زمان مطالعه: ۱۲ دقیقه
👤 تیم فنی

Domain Event نشان می‌دهد یک اتفاق مهم Business در Domain رخ داده است.

💡
Domain Event معمولاً Past Tense نام‌گذاری می‌شود؛ مثل PaymentCaptured یا RefundRequested.

تعریف Event

C#
public sealed record PaymentCaptured(
    Guid PaymentId,
    Money Amount,
    DateTime OccurredAt);

ایجاد Event داخل Aggregate

C#
public void Capture()
{
    if (Status != PaymentStatus.Authorized)
        throw new InvalidOperationException();

    Status = PaymentStatus.Paid;

    _domainEvents.Add(
        new PaymentCaptured(
            Id,
            Amount,
            DateTime.UtcNow));
}

Consumerهای احتمالی

  • Notification
  • Reporting
  • Loyalty
  • Audit
  • Settlement

Domain Event vs Integration Event

Domain Event Integration Event
داخل Domain/Bounded Context بین Contextها/Serviceها
مدل Business داخلی Contract خارجی
ممکن است In-Process باشد معمولاً Message Broker
⚠️
Domain Event و RabbitMQ Message الزاماً یک چیز نیستند. Integration Event معمولاً Contract مستقل خودش را دارد.

جمع‌بندی

Domain Event رویداد مهم Business را به‌صورت صریح وارد مدل می‌کند.
