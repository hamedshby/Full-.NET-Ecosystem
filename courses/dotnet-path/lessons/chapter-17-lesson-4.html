🧩 Coupling و Cohesion

17.4 — Cohesion چیست؟

📅 به‌روزرسانی: ۱۴۰۵/۰۵/۲۳
⏱️ زمان مطالعه: ۱۸ دقیقه
👤 تیم فنی

Cohesion نشان می‌دهد Responsibilityها و اعضای داخل یک Class یا Module چقدر با یکدیگر مرتبط هستند.

💡
اگر Methodها و Dataهای یک Class همگی برای یک هدف مشخص کار کنند، آن Class Cohesion بالایی دارد.

مثال ساده

C#
public class PaymentFeeCalculator
{
    public decimal CalculatePurchaseFee(decimal amount)
        => amount * 0.01m;

    public decimal CalculateRefundFee(decimal amount)
        => amount * 0.005m;
}

هر دو Method حول یک مفهوم یعنی Fee Calculation قرار دارند.

مثال Low Cohesion

C#
public class PaymentHelper
{
    public decimal CalculateFee(decimal amount) => amount * 0.01m;
    public void SendEmail() { }
    public void SaveToDatabase() { }
    public void GeneratePdf() { }
}

Fee، Email، Persistence و PDF مسئولیت‌های متفاوتی هستند.

Cohesion و SRP

SRP درباره Reason to Change است و Cohesion درباره میزان ارتباط رفتارهای داخل Component. این دو مرتبط‌اند، اما یکی نیستند.
