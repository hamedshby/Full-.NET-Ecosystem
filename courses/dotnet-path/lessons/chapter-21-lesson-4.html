21.4 — Aggregate

📅 به‌روزرسانی: ۱۴۰۵/۰۶/۱۵
⏱️ زمان مطالعه: ۱۲ دقیقه
👤 تیم فنی

Aggregate مجموعه‌ای از Entityها و Value Objectهاست که یک Consistency Boundary تشکیل می‌دهند.

💡
Aggregate فقط Collection چند Object نیست؛ مرزی است که Invariantهای داخل آن باید بعد از هر تغییر معتبر بمانند.

Aggregate و Transaction

به‌طور معمول یک Command باید یک Aggregate را تغییر دهد و Aggregate در پایان Transaction معتبر بماند.

⚠️
Aggregate بزرگ می‌تواند Transaction، Locking و Coupling را سنگین کند. مرز Aggregate باید بر اساس Invariant واقعی طراحی شود.

نکته مصاحبه‌ای

🎤
An aggregate is a consistency boundary that groups related entities and value objects which must maintain invariants together.

جمع‌بندی

Aggregate یعنی مرز Consistency، نه صرفاً Parent/Child در Database.
