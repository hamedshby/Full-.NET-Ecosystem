🧠 Domain-Driven Design

21.8 — Rich Domain Model

📅 به‌روزرسانی: ۱۴۰۵/۰۶/۱۵
⏱️ زمان مطالعه: ۱۲ دقیقه
👤 تیم فنی

Rich Domain Model مدلی است که State و Behavior مرتبط را کنار هم قرار می‌دهد.

مثال

C#
public class Payment
{
    public PaymentStatus Status
    {
        get;
        private set;
    }

    public void Authorize()
    {
        if (Status != PaymentStatus.Pending)
            throw new InvalidOperationException();

        Status = PaymentStatus.Authorized;
    }

    public void Capture()
    {
        if (Status != PaymentStatus.Authorized)
            throw new InvalidOperationException();

        Status = PaymentStatus.Paid;
    }
}

مزایا

  • Encapsulation قوی‌تر
  • Rule نزدیک State
  • Tell, Don't Ask
  • Invariant متمرکز
  • مدل نزدیک‌تر به Ubiquitous Language

Application Service

C#
payment.Authorize();
payment.Capture();

await repository.SaveAsync(
    payment,
    cancellationToken);
⚠️
Rich Domain Model به معنی Entityهای عظیم نیست. Behavior باید در مناسب‌ترین جای Domain قرار بگیرد.

نکته مصاحبه‌ای

🎤
A rich domain model keeps business behavior and state together so the model protects its own rules.

جمع‌بندی

در Rich Model، Object فقط Data Container نیست؛ Rule و Behavior هم دارد.
