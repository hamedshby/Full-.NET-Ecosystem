تعریف Class در C#

📅 به‌روزرسانی: ۱۴۰۵/۰۵/۲۳
⏱️ زمان مطالعه: ۱۸ دقیقه
👤 تیم فنی

در برنامه‌نویسی شی‌گرا، class قالبی است که مشخص می‌کند objectهای یک نوع چه داده‌هایی نگه می‌دارند و چه رفتارهایی می‌توانند انجام دهند. در C# تقریباً هر مدل دامنه‌ای مانند Customer، Order، Product یا BankAccount را می‌توان با یک class نمایش داد.

💡
class خودِ شیء واقعی نیست؛ تعریف یا نقشه‌ای است که از روی آن می‌توان یک یا چند object ساخت.

ساختار Class

برای تعریف یک class در C# از کلمهٔ کلیدی class استفاده می‌کنیم. داخل بدنهٔ class می‌توان اعضایی مانند Field، Property، Constructor و Method قرار داد.

C#
public class BankAccount
{
    private decimal _balance;

    public string AccountNumber { get; set; }

    public void Deposit(decimal amount)
    {
        _balance += amount;
    }
}

در این مثال BankAccount نام class است. متغیر _balance یک Field، عضو AccountNumber یک Property و Deposit یک Method است.

اجزای اصلی تعریف Class

بخش مثال کاربرد
Access Modifier public مشخص می‌کند class از کجا قابل دسترسی باشد.
Keyword class مشخص می‌کند در حال تعریف یک Class هستیم.
Class Name BankAccount نام Type را مشخص می‌کند.
Body { ... } اعضای Class داخل آن قرار می‌گیرند.

تعریف Field

Field متغیری است که داخل class تعریف می‌شود و بخشی از داده یا State یک object را نگه می‌دارد. هر object معمولاً نسخهٔ جداگانه‌ای از Fieldهای instance خود دارد.

C#
public class BankAccount
{
    private decimal _balance;
}

در این مثال _balance یک Field است که موجودی حساب را نگه می‌دارد. آن را private تعریف کرده‌ایم تا کد بیرون از class نتواند موجودی را مستقیماً تغییر دهد.

⚠️
در طراحی شی‌گرا معمولاً بهتر است Fieldهای داخلی را private نگه داریم و دسترسی به State را از طریق Property یا Methodهای کنترل‌شده فراهم کنیم.

تعریف Property

Property راه کنترل‌شده‌تری برای ارائه یا تغییر اطلاعات یک object است. Property از نظر نحوهٔ استفاده شبیه متغیر است، اما می‌تواند برای خواندن و نوشتن مقدار قوانین مشخصی داشته باشد.

C#
public class BankAccount
{
    public string AccountNumber { get; set; }
    public decimal Balance { get; private set; }
}

در AccountNumber هم get و هم set عمومی هستند؛ بنابراین کد بیرونی می‌تواند مقدار را بخواند و تغییر دهد. اما در Balance، بخش set خصوصی است؛ در نتیجه مقدار موجودی از بیرون فقط قابل خواندن است.

C#
var account = new BankAccount();

account.AccountNumber = "IR-1001";

// مجاز است
Console.WriteLine(account.Balance);

// مجاز نیست
// account.Balance = 1_000_000;

تعریف Method

Method رفتار یا عملیاتی را تعریف می‌کند که object قادر به انجام آن است. اگر Propertyها و Fieldها State را نمایش دهند، Methodها معمولاً Behavior را نمایش می‌دهند.

C#
public class BankAccount
{
    public decimal Balance { get; private set; }

    public void Deposit(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentOutOfRangeException(nameof(amount));

        Balance += amount;
    }
}

متد Deposit یک مقدار دریافت می‌کند، آن را بررسی می‌کند و فقط در صورت معتبر بودن، State حساب را تغییر می‌دهد. این طراحی بهتر از آن است که اجازه دهیم هر قسمت برنامه مستقیماً مقدار Balance را تغییر دهد.

ساختار یک Method

C#
public void Deposit(decimal amount)
{
    Balance += amount;
}
بخش مثال معنی
Access Modifier public متد از بیرون Class قابل فراخوانی است.
Return Type void متد مقداری برنمی‌گرداند.
Method Name Deposit نام رفتار را مشخص می‌کند.
Parameter decimal amount اطلاعات موردنیاز متد را دریافت می‌کند.

ساخت Object با new

پس از تعریف class هنوز objectای ایجاد نشده است. برای ساخت یک instance از class معمولاً از عملگر new استفاده می‌کنیم.

C#
BankAccount account = new BankAccount();

در این دستور، BankAccount نوع متغیر است، account متغیری است که reference مربوط به object را نگه می‌دارد و new BankAccount() یک instance جدید از BankAccount ایجاد می‌کند.

در C# جدید می‌توان همان کد را کوتاه‌تر نیز نوشت:

C#
BankAccount account = new();

استفاده از Object ساخته‌شده

C#
var account = new BankAccount();

account.AccountNumber = "IR-1001";
account.Deposit(500_000);

Console.WriteLine(account.AccountNumber);
Console.WriteLine(account.Balance);

متغیر account اکنون به یک object واقعی از نوع BankAccount اشاره می‌کند؛ بنابراین می‌توانیم از طریق آن به اعضای public مانند Propertyها و Methodها دسترسی داشته باشیم.

مثال کامل

حالا Field، Property، Method و ساخت object را در یک مثال کنار هم قرار می‌دهیم:

C#
public class BankAccount
{
    private decimal _balance;

    public string AccountNumber { get; set; }

    public decimal Balance
    {
        get { return _balance; }
    }

    public void Deposit(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentOutOfRangeException(nameof(amount));

        _balance += amount;
    }
}

var account = new BankAccount();

account.AccountNumber = "IR-1001";
account.Deposit(500_000);

Console.WriteLine($"شماره حساب: {account.AccountNumber}");
Console.WriteLine($"موجودی: {account.Balance}");

Class و Object را با هم اشتباه نگیریم

Class Object
تعریف یک Type است. یک Instance از آن Type است.
ساختار داده و رفتار را مشخص می‌کند. State واقعی خود را نگه می‌دارد.
BankAccount account1 و account2
C#
var account1 = new BankAccount();
var account2 = new BankAccount();

account1.Deposit(100_000);
account2.Deposit(800_000);

Console.WriteLine(account1.Balance); // 100000
Console.WriteLine(account2.Balance); // 800000

هر دو object از یک class ساخته شده‌اند، اما State مستقل دارند. تغییر موجودی account1 باعث تغییر موجودی account2 نمی‌شود.

✅
به‌صورت خلاصه: class مشخص می‌کند یک نوع چه داده‌هایی دارد و چه رفتارهایی انجام می‌دهد؛ سپس با new می‌توان instanceهای واقعی از آن ایجاد کرد.
