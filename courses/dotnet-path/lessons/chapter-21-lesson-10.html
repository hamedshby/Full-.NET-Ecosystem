21.10 — Encapsulation در Aggregate

📅 به‌روزرسانی: ۱۴۰۵/۰۶/۱۵
⏱️ زمان مطالعه: ۱۲ دقیقه
👤 تیم فنی

Encapsulation در Aggregate یعنی State داخلی فقط از طریق Behaviorهای معتبر Aggregate Root تغییر کند.

طراحی ضعیف

C#
public class Payment
{
    public List<Refund> Refunds
    {
        get;
        set;
    } = new();
}

Consumer می‌تواند آزادانه Collection را تغییر دهد.

طراحی بهتر

C#
public class Payment
{
    private readonly List<Refund>
        _refunds = new();

    public IReadOnlyCollection<Refund>
        Refunds => _refunds.AsReadOnly();

    public void RequestRefund(
        Money amount)
    {
        EnsureRefundIsAllowed(amount);

        _refunds.Add(
            Refund.Create(
                Guid.NewGuid(),
                amount));
    }
}

State Transition

C#
public void Cancel()
{
    if (Status == PaymentStatus.Settled)
        throw new InvalidOperationException(
            "Settled payment cannot be cancelled.");

    Status = PaymentStatus.Cancelled;
}
⚠️
Public Setter روی State حساس Domain معمولاً اجازه می‌دهد Invariant دور زده شود.

نکته مصاحبه‌ای

🎤
Encapsulation in an aggregate means all state changes go through the aggregate root so invariants cannot be bypassed.

جمع‌بندی

Aggregate Root باید API محدود و معناداری برای State Transitionهای معتبر ارائه دهد.
