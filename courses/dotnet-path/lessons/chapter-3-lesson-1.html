آشنایی با Constructor در C#

📅 به‌روزرسانی: ۱۴۰۵/۰۵/۲۳
⏱️ زمان مطالعه: ۱۸ دقیقه
👤 تیم فنی

وقتی با new یک object از یک class می‌سازیم، معمولاً لازم است object در همان لحظهٔ ایجاد مقداردهی یا برای استفاده آماده شود. در C# این مسئولیت را Constructor بر عهده دارد.

💡
Constructor متدی ویژه برای آماده‌سازی object هنگام ایجاد آن است. نام Constructor با نام Class یکسان است و Return Type ندارد؛ حتی void.

Constructor چیست؟

Constructor عضوی ویژه از class است که هنگام ساخته‌شدن یک instance اجرا می‌شود. برای مثال، یک حساب بانکی بدون شماره حساب معنای کاملی ندارد؛ بنابراین می‌توانیم دریافت شماره حساب را به Constructor منتقل کنیم.

C#
public class BankAccount
{
    public string AccountNumber { get; }

    public BankAccount(string accountNumber)
    {
        AccountNumber = accountNumber;
    }
}

وقتی object ساخته می‌شود، Constructor به‌صورت خودکار اجرا می‌شود:

C#
var account =
    new BankAccount("IR-1001");

Console.WriteLine(
    account.AccountNumber);

عبارت new BankAccount("IR-1001") یک instance جدید ایجاد می‌کند و مقدار "IR-1001" را به Constructor می‌فرستد.

ساختار Constructor

C#
public BankAccount(string accountNumber)
{
    AccountNumber = accountNumber;
}
بخش مثال توضیح
Access Modifier public مشخص می‌کند Constructor از کجا قابل استفاده است.
نام BankAccount باید با نام Class یکسان باشد.
Parameters string accountNumber اطلاعات لازم برای ایجاد object را دریافت می‌کند.
Body { ... } منطق مقداردهی و آماده‌سازی object است.
⚠️
Constructor هیچ Return Type ندارد. نوشتن void BankAccount() Constructor ایجاد نمی‌کند؛ بلکه از نظر syntax یک Method با نام نامعتبر/نامناسب نسبت به هدف موردنظر خواهد بود.

Default Constructor

Constructor بدون Parameter را معمولاً Parameterless Constructor می‌نامیم. در آموزش‌های مقدماتی اغلب از اصطلاح Default Constructor نیز برای آن استفاده می‌شود.

C#
public class BankAccount
{
    public decimal Balance { get; private set; }

    public BankAccount()
    {
        Balance = 0;
    }
}

برای ساخت object نیازی به ارسال Argument نداریم:

C#
var account = new BankAccount();

Console.WriteLine(account.Balance);
// 0

Constructor خودکار Compiler

اگر برای یک class هیچ Instance Constructor تعریف نکنیم، C# برای یک class معمولی یک public parameterless constructor به‌صورت ضمنی فراهم می‌کند.

C#
public class BankAccount
{
    public decimal Balance { get; set; }
}

var account = new BankAccount();

در این مثال خودمان Constructor ننوشته‌ایم، اما new BankAccount() قابل استفاده است.

⚠️
اگر خودتان یک Instance Constructor پارامتردار تعریف کنید، Compiler دیگر به‌طور خودکار همان public parameterless constructor را برایتان ایجاد نمی‌کند.
C#
public class BankAccount
{
    public string AccountNumber { get; }

    public BankAccount(
        string accountNumber)
    {
        AccountNumber = accountNumber;
    }
}

// Compile Error
// var account = new BankAccount();

var account =
    new BankAccount("IR-1001");

Parameterized Constructor

Constructor می‌تواند Parameter دریافت کند. این کار زمانی مفید است که object برای قرارگرفتن در یک State معتبر، از همان ابتدا به اطلاعات مشخصی نیاز داشته باشد.

C#
public class BankAccount
{
    public string AccountNumber { get; }
    public string OwnerName { get; }
    public decimal Balance { get; private set; }

    public BankAccount(
        string accountNumber,
        string ownerName)
    {
        AccountNumber = accountNumber;
        OwnerName = ownerName;
        Balance = 0;
    }
}
C#
var account = new BankAccount(
    "IR-1001",
    "Hamed");

Console.WriteLine(
    account.AccountNumber);

Console.WriteLine(
    account.OwnerName);

در این طراحی نمی‌توان یک BankAccount بدون AccountNumber و OwnerName ساخت. این موضوع به حفظ invariantهای سادهٔ object کمک می‌کند.

Validation داخل Constructor

Constructor می‌تواند قبل از ساخت کامل object، ورودی‌های ضروری را بررسی کند:

C#
public class BankAccount
{
    public string AccountNumber { get; }

    public BankAccount(
        string accountNumber)
    {
        if (string.IsNullOrWhiteSpace(
            accountNumber))
        {
            throw new ArgumentException(
                "Account number is required.",
                nameof(accountNumber));
        }

        AccountNumber = accountNumber;
    }
}

اکنون ساخت حساب با شمارهٔ خالی مجاز نیست:

C#
// Exception
// var account =
//     new BankAccount("");

var account =
    new BankAccount("IR-1001");
✅
اگر یک مقدار برای معتبر بودن object ضروری است، دریافت آن از Constructor معمولاً بهتر از ساخت object ناقص و مقداردهی آن در چند مرحله است.

Constructor Overloading

همان‌طور که Methodها می‌توانند Overload داشته باشند، یک class نیز می‌تواند چند Constructor با Parameter Listهای متفاوت داشته باشد.

C#
public class BankAccount
{
    public string AccountNumber { get; }
    public string OwnerName { get; }
    public decimal Balance { get; private set; }

    public BankAccount()
    {
        AccountNumber = "Unknown";
        OwnerName = "Unknown";
        Balance = 0;
    }

    public BankAccount(
        string accountNumber)
    {
        AccountNumber = accountNumber;
        OwnerName = "Unknown";
        Balance = 0;
    }

    public BankAccount(
        string accountNumber,
        string ownerName)
    {
        AccountNumber = accountNumber;
        OwnerName = ownerName;
        Balance = 0;
    }
}

اکنون object را می‌توان به چند شکل ساخت:

C#
var account1 =
    new BankAccount();

var account2 =
    new BankAccount("IR-1001");

var account3 =
    new BankAccount(
        "IR-1002",
        "Hamed");

Compiler با توجه به تعداد و نوع Argumentها تشخیص می‌دهد کدام Constructor باید اجرا شود.

Overload بر اساس نوع Parameter

C#
public class Transaction
{
    public Transaction(long id)
    {
        // ...
    }

    public Transaction(Guid id)
    {
        // ...
    }
}

هر دو Constructor یک Parameter دارند، اما نوع Parameter متفاوت است؛ بنابراین دو overload مجزا محسوب می‌شوند.

مقایسه Constructorها

نوع نمونه کاربرد
Parameterless BankAccount() ساخت object بدون Argument
Parameterized BankAccount(string number) دریافت اطلاعات هنگام ایجاد object
Overloaded چند Constructor ارائهٔ چند روش معتبر برای ساخت object

مثال کامل

C#
public class BankAccount
{
    public string AccountNumber { get; }
    public string OwnerName { get; }
    public decimal Balance { get; private set; }

    public BankAccount()
    {
        AccountNumber = "Unknown";
        OwnerName = "Unknown";
        Balance = 0;
    }

    public BankAccount(
        string accountNumber)
    {
        if (string.IsNullOrWhiteSpace(
            accountNumber))
        {
            throw new ArgumentException(
                "Account number is required.",
                nameof(accountNumber));
        }

        AccountNumber = accountNumber;
        OwnerName = "Unknown";
        Balance = 0;
    }

    public BankAccount(
        string accountNumber,
        string ownerName,
        decimal initialBalance)
    {
        if (string.IsNullOrWhiteSpace(
            accountNumber))
        {
            throw new ArgumentException(
                "Account number is required.",
                nameof(accountNumber));
        }

        if (initialBalance < 0)
        {
            throw new ArgumentOutOfRangeException(
                nameof(initialBalance));
        }

        AccountNumber = accountNumber;
        OwnerName = ownerName;
        Balance = initialBalance;
    }
}
C#
var account1 =
    new BankAccount();

var account2 =
    new BankAccount("IR-1001");

var account3 =
    new BankAccount(
        "IR-1002",
        "Hamed",
        1_000_000);

Console.WriteLine(
    account3.Balance);
// 1000000

سه Constructor سه روش مختلف برای ایجاد BankAccount ارائه می‌کنند. نسخهٔ پارامتردار همچنین ورودی‌ها را بررسی می‌کند تا object با State نامعتبر ساخته نشود.

✅
Constructor نقطهٔ ورود object به سیستم است. طراحی مناسب Constructor کمک می‌کند object از همان لحظهٔ ایجاد در یک State معتبر قرار داشته باشد. Parameterized Constructor برای دریافت داده‌های ضروری و Constructor Overloading برای ارائهٔ چند روش معتبر ایجاد object استفاده می‌شود.
