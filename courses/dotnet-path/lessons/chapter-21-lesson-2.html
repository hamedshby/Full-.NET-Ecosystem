21.2 — Entity

📅 به‌روزرسانی: ۱۴۰۵/۰۶/۱۵
⏱️ زمان مطالعه: ۱۲ دقیقه
👤 تیم فنی

Entity Objectای است که Identity مستقل دارد و Business می‌خواهد آن را در طول زمان دنبال کند.

💡
دو Payment با Amount یکسان هنوز دو Entity متفاوت‌اند، چون PaymentId متفاوت دارند.

مثال Payment Entity

C#
public class Payment
{
    public Guid Id { get; }
    public Money Amount { get; }
    public PaymentStatus Status { get; private set; }

    public Payment(Guid id, Money amount)
    {
        Id = id;
        Amount = amount;
        Status = PaymentStatus.Pending;
    }
}

Identity مهم‌تر از Attribute

C#
var p1 = new Payment(
    Guid.NewGuid(),
    new Money(100_000, "IRR"));

var p2 = new Payment(
    Guid.NewGuid(),
    new Money(100_000, "IRR"));

مقدارها مشابه‌اند، اما Entityها متفاوت‌اند.

Entity vs Value Object

Entity Value Object
Identity دارد Identity مستقل ندارد
Lifecycle دارد معمولاً Immutable است
با Id شناخته می‌شود با Value شناخته می‌شود

نکته مصاحبه‌ای

🎤
An entity is defined by its identity and lifecycle, not only by its attributes.
