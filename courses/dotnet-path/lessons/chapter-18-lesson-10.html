🏗️ اصول طراحی Object-Oriented

18.10 — YAGNI

📅 به‌روزرسانی: ۱۴۰۵/۰۶/۱۵
⏱️ زمان مطالعه: ۱۲ دقیقه
👤 تیم فنی

YAGNI — You Aren't Gonna Need It می‌گوید Feature، Abstraction یا Infrastructure را تا زمانی که Requirement واقعی برای آن نداریم، صرفاً برای آیندهٔ فرضی نسازیم.

مثال

فرض کنید Payment System فعلاً فقط SQL Server دارد، اما از روز اول برای احتمال مهاجرت آینده به پنج Database مختلف یک Framework پیچیده می‌سازیم.

Text
IDatabaseProvider
    -> SqlServerProvider
    -> PostgreSqlProvider
    -> MongoProvider
    -> OracleProvider
    -> ProviderFactory
    -> ProviderResolver

اگر چنین Requirementی وجود ندارد، هزینهٔ Design، Test و Maintenance را امروز پرداخت کرده‌ایم برای چیزی که شاید هیچ‌وقت استفاده نشود.

نسخه متناسب با نیاز امروز

C#
builder.Services.AddDbContext<PaymentDbContext>(
    options =>
        options.UseSqlServer(connectionString));

YAGNI چه چیزی را کاهش می‌دهد؟

  • Speculative Generality
  • Unused Features
  • Abstractionهای بدون Consumer واقعی
  • Configurationهای غیرضروری
  • هزینهٔ Test و Maintenance

YAGNI و طراحی آینده‌پذیر

YAGNI نمی‌گوید Architecture را بدون فکر طراحی کنیم. می‌توان Boundaryهای تمیز، Naming خوب، Tests و Encapsulation مناسب داشت بدون اینکه Feature آینده را از قبل پیاده‌سازی کنیم.

مثال Microservices

اگر یک Domain کوچک، یک تیم و Deployment ساده داریم، تبدیل فوری آن به ده Microservice فقط به دلیل «شاید بعداً Scale کنیم» می‌تواند نقض YAGNI و KISS باشد.

⚠️
YAGNI نباید بهانه‌ای برای نادیده گرفتن Requirementهای قطعی، Security، Observability، Capacity Planning یا Technical Constraintهای شناخته‌شده باشد.

ارتباط DRY، KISS و YAGNI

اصل سؤال کلیدی
DRY آیا یک Knowledge واقعی را چند بار تعریف کرده‌ایم؟
KISS آیا راه ساده‌تری برای Requirement فعلی وجود دارد؟
YAGNI آیا واقعاً امروز به این Feature/Abstraction نیاز داریم؟

نکته مصاحبه‌ای

🎤
YAGNI means avoiding speculative features and abstractions until there is a real requirement for them.

جمع‌بندی فصل 18

اصول این فصل یک هدف مشترک دارند: Objectها و Componentهایی بسازیم که مسئولیت روشن، Dependency کنترل‌شده و Complexity متناسب با نیاز واقعی داشته باشند.

✅
