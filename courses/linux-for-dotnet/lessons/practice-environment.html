محیط تمرین: WSL در ویندوز، ماشین مجازی یا لینوکس موجود

قرار است یک محیط لینوکس باز کنی و از داخل آن نام کاربر، نام هسته و مسیر پوشهٔ شخصی‌ات را ببینی. برای این فصل یک ترمینال با Bash کافی است؛ نصب .NET SDK را در فصل توسعه دنبال می‌کنیم.

مسیر اول: WSL روی ویندوز

اگر ویندوز داری و می‌توانی روی آن نرم‌افزار نصب کنی، از این مسیر شروع کن. WSL، کوتاه‌شدهٔ Windows Subsystem for Linux، به تو اجازه می‌دهد در کنار برنامه‌های ویندوز، ابزارهای لینوکس را هم اجرا کنی.

  1. در PowerShell ویندوز، wsl --list --verbose را اجرا کن. اگر Ubuntu در فهرست است، از منوی Start آن را باز کن و به مرحلهٔ بررسی برو.
  2. اگر Ubuntu را نداری، PowerShell را با دسترسی Administrator باز کن و دستور زیر را بزن. پس از نصب، ویندوز را راه‌اندازی مجدد کن اگر برای تکمیل نصب از تو خواسته شد.
PowerShell
wsl --install -d Ubuntu

Ubuntu را از منوی Start باز کن. در اولین اجرا، وقتی از تو خواست، نام کاربری و رمز عبور لینوکس را بساز. هنگام تایپ رمز ممکن است هیچ نویسه‌ای روی صفحه نبینی؛ این رفتار عادی است. دستورهای تمرین را در پنجرهٔ Ubuntu وارد کن.

اگر گزینهٔ نصب شناخته نشد یا پیغام مجازی‌سازی دیدی، به راهنمای WSL در Microsoft Learn مراجعه کن. اگر روی سیستم سازمانی دسترسی نصب نداری، از محیط لینوکسی که سازمان در اختیارت می‌گذارد استفاده کن.

مسیر دوم: Ubuntu در ماشین مجازی

ماشین مجازی مثل یک کامپیوتر جدا درون کامپیوتر اصلی است. اگر می‌خواهی خود دسکتاپ Ubuntu را هم ببینی، یک ماشین مجازی بساز، فایل نصب Ubuntu را به آن بده و Ubuntu را روی دیسک مجازی همان ماشین نصب کن. بعد از ورود به Ubuntu، برنامهٔ Terminal را در ماشین مجازی باز کن. راهنمای تصویری Ubuntu برای VirtualBox انتخاب فایل نصب و ساخت ماشین را نشان می‌دهد.

مسیر سوم: لینوکس از قبل آماده است

اگر همین حالا از لینوکس استفاده می‌کنی، Terminal را باز کن. برای هماهنگی با مثال‌ها می‌توانی در ترمینال bash را اجرا کنی تا وارد Bash شوی، به شرطی که نصب باشد.

بررسی: آیا محیط تمرین آماده است؟

این دستورها را در ترمینال لینوکس اجرا کن:

Bash
whoami
uname -s
cd ~
pwd
خروجی نمونه
sara
Linux
/home/sara

whoami نام کاربر فعلی و uname -s نام هسته را چاپ می‌کند. cd ~ به پوشهٔ شخصی می‌رود و معمولاً چیزی چاپ نمی‌کند؛ pwd مسیر فعلی را نشان می‌دهد. نام کاربر و مسیر تو ممکن است متفاوت باشند. اگر whoami کاربر root را نشان داد، تمرین‌ها را با حساب عادی خودت ادامه بده.

تمرین کوتاه

یک پوشه برای تمرین‌های دوره بساز و مسیرش را ببین. mkdir -p پوشه را می‌سازد و اگر همان پوشه از قبل وجود داشته باشد، خطا نمی‌دهد. $HOME به مسیر پوشهٔ شخصی‌ات تبدیل می‌شود.

Bash
mkdir -p "$HOME/linux-practice"
cd "$HOME/linux-practice"
pwd

خروجی باید به /linux-practice ختم شود؛ برای مثال /home/sara/linux-practice.
