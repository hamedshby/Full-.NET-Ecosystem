آشنایی با لینوکس، توزیع‌ها و Ubuntu

فرض کن همکارت می‌گوید «برنامه روی لینوکس اجرا می‌شود» و وقتی نام محیطش را می‌پرسی، می‌گوید «Ubuntu». هر دو جواب درست‌اند. این دو دستور نشان می‌دهند هر کدام به چه چیزی اشاره می‌کند.

نام هسته و نام توزیع را ببین

اگر ترمینال لینوکس داری، دستورها را یکی‌یکی اجرا کن. اگر هنوز محیط نداری، خروجی نمونه را بخوان و بعد از درس راه‌اندازی به اینجا برگرد.

Bash
uname -s
cat /etc/os-release
خروجی نمونه
Linux

PRETTY_NAME="Ubuntu 24.04 LTS"
NAME="Ubuntu"
ID=ubuntu
  • uname -s نام هسته را چاپ می‌کند. هسته بخش اصلی سیستم‌عامل است که منابعی مثل حافظه و پردازنده را بین برنامه‌ها مدیریت می‌کند. در خط اول خروجی نام آن را می‌بینی: Linux.
  • cat /etc/os-release محتوای فایل شناسایی توزیع را نشان می‌دهد. توزیع یک مجموعهٔ قابل نصب است که هستهٔ Linux را همراه با ابزارها و بسته‌های نرم‌افزاری فراهم می‌کند. خط PRETTY_NAME نام قابل خواندن توزیع را نشان می‌دهد و ID شناسهٔ کوتاه آن است. فایل واقعی معمولاً خط‌های بیشتری دارد.

چرا برای برنامه‌نویس ‎.NET مهم است؟

Ubuntu و Fedora هر دو از هستهٔ Linux استفاده می‌کنند، ولی ابزار نصب نرم‌افزار و بسته‌هایشان می‌تواند فرق کند. مثلاً برای نصب .NET SDK، یعنی ابزارهای ساخت و تست برنامهٔ .NET، اول نام و نسخهٔ توزیع را از /etc/os-release بخوان. با این اطلاعات می‌توانی راهنمای نصب مناسب محیطت را انتخاب کنی.

تمرین کوتاه

از روی نمونه بگو اگر همکارت به جای Ubuntu از Fedora استفاده کند، انتظار داری خروجی کدام دستور تغییر کند؟ اگر محیط آماده داری، نام هسته و توزیع خودت را هم یادداشت کن.

پاسخ تمرین

خروجی uname -s همچنان Linux است. نام توزیع و شناسهٔ آن در خروجی cat /etc/os-release با هم فرق می‌کنند.

برای مطالعهٔ بیشتر: راهنمای GNU برای uname و راهنمای نصب .NET برای توزیع‌های لینوکس.
