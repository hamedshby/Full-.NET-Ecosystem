۱. آشنایی و آماده‌سازی محیط

  1. آشنایی با لینوکس، توزیع‌ها و Ubuntu
  2. محیط تمرین: WSL در ویندوز، ماشین مجازی یا لینوکس موجود
  3. تفاوت ترمینال، خط فرمان و Bash
  4. ساختار دستور، راهنمای man و --help، تکمیل خودکار و تاریخچه

۲. فایل‌ها و مسیرها

  • ساختار پوشه‌ها: ریشه، پوشهٔ شخصی و پوشه‌های سیستمی
  • مسیر مطلق و نسبی، پوشهٔ جاری و حرکت با pwd، ls و cd
  • ساخت، کپی، جابه‌جایی و حذف فایل و پوشه
  • فایل‌های مخفی، نام‌های دارای فاصله و حساسیت به بزرگی و کوچکی حروف

۳. خواندن متن و جست‌وجو

  • خواندن فایل و دنبال کردن گزارش‌ها با cat، less و tail
  • پیدا کردن فایل با find و جست‌وجوی متن با grep
  • خروجی معمولی، خروجی خطا، تغییر مسیر خروجی و Pipe
  • ویرایش فایل تنظیمات با nano

۴. کاربران و مجوزها

  • کاربر، گروه و مالکیت فایل
  • خواندن مجوزهای فایل و پوشه و تغییر آن‌ها با chmod
  • کاربر root و کاربرد sudo

۵. ابزارها و تنظیمات توسعه

  • نصب و به‌روزرسانی بسته‌ها در Ubuntu با apt
  • متغیرهای محیطی، PATH و پیدا کردن محل یک دستور
  • تنظیمات Bash و تفاوت تنظیم موقت با تنظیم در .bashrc
  • کار روی یک مخزن Git از ترمینال

۶. پردازه‌ها و شبکهٔ محلی

  • پردازه چیست و چطور برنامه‌های در حال اجرا را پیدا و متوقف کنیم؟
  • نشانی IP، پورت و localhost
  • آزمایش پاسخ یک برنامهٔ محلی با curl
  • عیب‌یابی اولیه: خروجی برنامه، پورت اشغال‌شده و مجوز دسترسی

۷. توسعهٔ .NET در لینوکس

  • تفاوت .NET SDK و Runtime و بررسی نصب با dotnet --info
  • ساخت، اجرا و تست یک پروژهٔ .NET از ترمینال
  • تفاوت‌های ویندوز و لینوکس در پروژه: مسیرها، نام فایل‌ها و پایان خط
  • تمرین پایانی: اجرای یک ASP.NET Core Web API، تنظیم محیط و بررسی پاسخ محلی
