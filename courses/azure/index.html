سرفصل‌های آموزش Azure

ترتیب ماژول‌ها از شناخت Cloud آغاز می‌شود و در پروژهٔ نهایی، سرویس‌ها را در کنار هم به‌کار می‌گیریم. موضوع‌های پرکاربرد برای توسعه‌دهندهٔ .NET تمرین عملی دارند؛ سرویس‌های تخصصی‌تر در حد نیاز معرفی می‌شوند.

مفاهیم پایه و معماری Azure

با مدل‌های Cloud و ساختار منابع Azure آشنا می‌شویم تا بدانیم هر سرویس کجا قرار می‌گیرد و چه کسی مسئول مدیریت آن است.

  • IaaS، PaaS و SaaS
  • Region و Availability Zone
  • Subscription و Resource Group
  • هزینه و Shared Responsibility

Azure App Service

  • ساخت و انتشار ASP.NET Core API
  • App Service Plan و Scale
  • Configuration و Environment Variables
  • Deployment Slots و HTTPS

  • Azure Functions
  • Virtual Machines
  • Container Apps
  • آشنایی با AKS و زمان استفاده از آن

پایگاه‌داده را ایجاد می‌کنیم، API را به آن متصل می‌کنیم و با دسترسی، مهاجرت و پشتیبان‌گیری آشنا می‌شویم.

  • Azure SQL Database
  • Firewall و اتصال امن
  • EF Core و Database Migration
  • Backup و دسترس‌پذیری

یاد می‌گیریم فایل و دادهٔ ساده را در Storage نگهداری کنیم و از طریق برنامهٔ .NET به آن دسترسی داشته باشیم.

  • Storage Account و Blob Storage
  • File، Queue و Table Storage
  • Access Tier و SAS
  • Azure Storage SDK

Microsoft Entra ID و مدیریت رازها

  • Authentication و Authorization
  • Managed Identity و RBAC
  • Key Vault و Secrets
  • App Registration و OAuth / OIDC

  • Queue، Topic و Subscription
  • Dead Letter Queue و Retry
  • Duplicate Detection و Sessions
  • SDK سرویس با C#

  • Azure Container Registry
  • Azure Container Apps
  • AKS و شبکهٔ Containerها

  • GitHub Actions
  • Build، Test و Deploy
