ارشدزمان مطالعه: ۸ دقیقه

یک حلقه foreach چگونه ترجمه و اجرا می‌شود؟

پاسخ کوتاه مصاحبه‌ای

کامپایلر الگوی enumerator را می‌یابد، `GetEnumerator` می‌گیرد، با `MoveNext` پیش می‌رود، `Current` را می‌خواند و در صورت نیاز enumerator را dispose می‌کند.

توضیح کامل

foreach فقط به IEnumerable محدود نیست و pattern-based enumeration را پشتیبانی می‌کند. آرایه‌ها ممکن است به حلقهٔ بهینه‌تر تبدیل شوند. struct enumerator می‌تواند allocation را کم کند، اما استفاده از interface ممکن است boxing ایجاد کند.

در API پرکاربرد، نوع static مجموعه و enumerator روی allocation اثر دارد؛ فقط پس از اندازه‌گیری بهینه کنید.

C#
using var e = source.GetEnumerator();
while (e.MoveNext())
{
    var item = e.Current;
    Consume(item);
}

نکات کلیدی

  • foreach فقط به IEnumerable محدود نیست و pattern-based enumeration را پشتیبانی می‌کند
  • آرایه‌ها ممکن است به حلقهٔ بهینه‌تر تبدیل شوند
  • struct enumerator می‌تواند allocation را کم کند، اما استفاده از interface ممکن است boxing ایجاد کند

اشتباهات رایج

  • فرض اینکه همیشه index-based است
  • تغییر collection در حین enumeration.
