یک حلقه foreach چگونه ترجمه و اجرا می‌شود؟

پاسخ کوتاه مصاحبه‌ای

foreach از یک enumeration pattern استفاده می‌کند: دریافت enumerator، فراخوانی MoveNext، خواندن Current و در صورت نیاز Dispose. Compiler براساس type ایستای collection و pattern موجود شکل مناسب کد را تولید می‌کند.

مدل ذهنی ساده

foreach جادو نیست؛ یک cursor روی sequence حرکت می‌کند. هر بار MoveNext می‌پرسد element بعدی وجود دارد یا نه و Current همان element را می‌دهد. loop body با آن value اجرا می‌شود و در پایان resource مربوط به enumerator آزاد می‌شود.

توضیح کامل

Compiler ابتدا collection type، enumerator type و iteration type را تعیین می‌کند. اگر pattern مناسب GetEnumerator/MoveNext/Current وجود داشته باشد، الزاماً نیاز نیست type مستقیماً IEnumerable<T> را پیاده کند. برای array ممکن است lowering به شکل بهینهٔ index-based انجام شود. اگر enumerator disposable باشد، cleanup در ساختاری شبیه try/finally قرار می‌گیرد. ref و ref readonly foreach نیز برای iteration روی reference به element قواعد جدا دارند.

C#
using var e = source.GetEnumerator();
while (e.MoveNext())
{
    var item = e.Current;
    Consume(item);
}

رفتار مثال: کد while مفهوم پایه را نشان می‌دهد: e یک بار ساخته می‌شود، MoveNext پیش می‌رود و Current فقط پس از موفقیت آن خوانده می‌شود. using تضمین می‌کند Dispose اجرا شود. این کد ترجمهٔ دقیق تمام foreachها نیست؛ Compiler برای typeهای خاص بهینه‌سازی متفاوتی دارد.

نکات کلیدی

  • foreach بر enumeration pattern تکیه دارد.
  • Current پس از موفقیت MoveNext معتبر است.
  • نوع ایستای collection می‌تواند بر allocation و dispatch اثر بگذارد.

اشتباهات رایج

  • فرض اینکه همیشه index-based است
  • تغییر collection در حین enumeration.

جزئیات عمیق‌تر

یک struct enumerator می‌تواند allocation را حذف کند، اما تبدیل آن به interface ممکن است Boxing بسازد. تغییر ساختاری collection هنگام enumeration معمولاً enumerator را invalid می‌کند. برای Performance، foreach را کورکورانه با for جایگزین نکنید؛ generated code و workload واقعی را Benchmark کنید.

در پروژهٔ واقعی

در API پرکاربرد، نوع static مجموعه و enumerator روی allocation اثر دارد؛ فقط پس از اندازه‌گیری بهینه کنید.

جمع‌بندی برای مصاحبه
