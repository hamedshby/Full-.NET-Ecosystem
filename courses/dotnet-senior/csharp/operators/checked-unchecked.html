checked و unchecked چگونه Overflow عددی را کنترل می‌کنند؟

پاسخ کوتاه مصاحبه‌ای

checked برای arithmetic و conversionهای integral مشخص می‌کند Overflow باید OverflowException ایجاد کند؛ unchecked wrap شدن نتیجه را طبق representation مقصد مجاز می‌کند. این رفتار برای floating-point و decimal یکسان نیست.

مدل ذهنی ساده

اگر int.MaxValue را یک واحد زیاد کنیم، نتیجه در int جا نمی‌شود. checked این خارج‌شدن از محدوده را خطا می‌داند. unchecked bitهای اضافه را کنار می‌گذارد و value از سمت دیگر محدوده ظاهر می‌شود. انتخاب باید براساس معنی داده باشد، نه راحتی عبور از خطا.

توضیح کامل

checked(max + 1) در Runtime OverflowException می‌دهد. unchecked(max + 1) معمولاً int.MinValue تولید می‌کند. constant expressionهای خارج از محدوده اغلب در Compile Time رد می‌شوند و unchecked می‌تواند intent را صریح کند. decimal همیشه Overflow را بررسی می‌کند، درحالی‌که floating-point به Infinity می‌رسد و checked آن را به integer semantics تبدیل نمی‌کند.

C#
int max = int.MaxValue;
try { int next = checked(max + 1); }
catch (OverflowException) { /* گزارش */ }
int wrapped = unchecked(max + 1);

رفتار مثال: در try نخست exception گرفته می‌شود و next ساخته نمی‌شود. wrapped برابر -2147483648 خواهد بود. این wrap برای محاسبهٔ مالی یا تعداد امنیتی معمولاً bug است، ولی در برخی الگوریتم‌های Hash بخشی عمدی از طراحی است.

نکات کلیدی

  • checked روی عملیات و conversionهای integral اثر می‌گذارد.
  • unchecked wrap را صریحاً می‌پذیرد.
  • نوع عددی و context Compile Time یا Runtime در نتیجه مهم است.

اشتباهات رایج

  • تصور اینکه floating-point overflow را exception می‌کند
  • استفاده از unchecked در محاسبات مالی.

جزئیات عمیق‌تر

تنظیم CheckForOverflowUnderflow پروژه می‌تواند context پیش‌فرض برخی عملیات را تغییر دهد، اما بهتر است boundaryهای حساس با checked صریح باشند. این setting روی هر operation به یک شکل اثر ندارد؛ مستندات operation و type را بررسی کنید.

در پروژهٔ واقعی

در شمارندهٔ امنیتی یا تبدیل ورودی checked مناسب است؛ در الگوریتم hash ممکن است wrap عمدی باشد.

جمع‌بندی برای مصاحبه

دامنهٔ integer، exception در checked و کاربرد عمدی unchecked را با مثال مرزی بگویید.
