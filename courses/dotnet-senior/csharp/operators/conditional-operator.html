مقدماتیزمان مطالعه: ۶ دقیقه

عملگر سه‌تایی ?: چه زمانی از if مناسب‌تر است؟

پاسخ کوتاه مصاحبه‌ای

`?:` یک expression برای انتخاب یک مقدار است؛ `if` statement برای کنترل چند مرحله یا side effect خواناتر است.

توضیح کامل

conditional operator برای assignment، return و expressionهای کوچک مناسب است. زنجیره‌های تو در تو خوانایی را کاهش می‌دهند و بهتر است به if یا تابع نام‌دار تبدیل شوند.

در mapping کوتاه یا تعیین label استفاده کنید؛ منطق کسب‌وکار چندشاخه را واضح نگه دارید.

C#
string label = score >= 10 ? "قبول" : "نیازمند تلاش";
return user is null ? Result.NotFound() : Result.Ok(user);

نکات کلیدی

  • conditional operator برای assignment، return و expressionهای کوچک مناسب است
  • زنجیره‌های تو در تو خوانایی را کاهش می‌دهند و بهتر است به if یا تابع نام‌دار تبدیل شوند

اشتباهات رایج

  • استفاده برای چند دستور
  • nesting پیچیده فقط برای کوتاه‌شدن کد.

در پروژهٔ واقعی
