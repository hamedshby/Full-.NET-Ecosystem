Record چه تفاوتی با Class دارد؟

پاسخ کوتاه مصاحبه‌ای

record class مانند class یک Reference Type است، اما به‌صورت پیش‌فرض Value Equality، نمایش مناسب و with expression دارد. class عادی به‌صورت پیش‌فرض Reference Equality دارد و برای entityهای دارای identity معمولاً روشن‌تر است.

مدل ذهنی ساده

برای entity بپرسید «آیا دو instance با داده یکسان هنوز دو چیز جدا هستند؟» اگر بله، class با identity مناسب است. برای data carrier بپرسید «آیا تمام معنای object از مقدار memberها می‌آید؟» اگر بله، record می‌تواند equality و copy موردنیاز را کم‌هزینه‌تر بیان کند.

توضیح کامل

Compiler برای record memberهای equality، GetHashCode، ToString و سازوکار with را تولید می‌کند. این به معنی immutable بودن مطلق نیست؛ propertyهای mutable همچنان قابل تغییرند. with یک shallow copy می‌سازد، بنابراین referenceهای داخل record بین نسخه‌ها مشترک می‌مانند. class عادی نیز می‌تواند Value Equality را دستی پیاده کند، و record نیز می‌تواند identity داشته باشد، اما defaultهای هرکدام intent متفاوتی منتقل می‌کنند.

C#
public record UserSummary(int Id, string Name);
var first = new UserSummary(1, "Sara");
var renamed = first with { Name = "Mina" };

رفتار مثال: دو Money("USD", 10) record با == برابرند چون componentهایشان برابر است. دو Customer class با نام یکسان به‌صورت پیش‌فرض برابر نیستند چون instanceهای جدا هستند. order2 = order1 with { Status = "Paid" } object بیرونی تازه می‌سازد، ولی اگر Items یک List باشد همان List می‌تواند مشترک بماند.

نکات کلیدی

  • record class هنوز Reference Type است.
  • record به‌صورت پیش‌فرض Value Equality دارد.
  • `with` shallow copy است و immutable بودن عمیق تضمین نمی‌کند.

اشتباهات رایج

  • تصور value type بودن record
  • تصور deep copy بودن with.

جزئیات عمیق‌تر

در Entity Framework و modelهای identityمحور باید اثر equality تولیدشده را آگاهانه بررسی کنید. record برای DTO، command، event و value object بسیار مناسب است. برای object دارای lifecycle و mutable state گسترده، class عادی معمولاً intent را شفاف‌تر نشان می‌دهد.

در پروژهٔ واقعی

برای command/event/DTO با semantics مقداری record مناسب است؛ entity mutable با identity معمولاً class است.

جمع‌بندی برای مصاحبه

reference type بودن record class را کنار Value Equality و with توضیح دهید.
