متوسطزمان مطالعه: ۶ دقیقه

چه زمانی از HashSet، SortedSet یا Dictionary استفاده می‌کنیم؟

پاسخ کوتاه مصاحبه‌ای

HashSet برای عضویت یکتا و سریع، SortedSet برای یکتایی همراه ترتیب مرتب، و Dictionary برای نگاشت کلید به مقدار است.

توضیح کامل

HashSet ترتیب قراردادی ندارد. SortedSet عملیات range و min/max می‌دهد اما مقایسهٔ ترتیبی لازم دارد. Dictionary وقتی دادهٔ مرتبط با هر کلید وجود دارد مناسب است.

برای dedup تگ HashSet، leaderboard مرتب SortedSet و catalog قیمت Dictionary انتخاب کنید.

C#
var tags = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
var ranks = new SortedSet<int> { 3, 1, 2 };
var prices = new Dictionary<string, decimal> { ["book"] = 12m };

نکات کلیدی

  • HashSet ترتیب قراردادی ندارد
  • SortedSet عملیات range و min/max می‌دهد اما مقایسهٔ ترتیبی لازم دارد
  • Dictionary وقتی دادهٔ مرتبط با هر کلید وجود دارد مناسب است

اشتباهات رایج

  • وابستگی به ترتیب فعلی HashSet
  • استفاده از Dictionary به‌جای set.
