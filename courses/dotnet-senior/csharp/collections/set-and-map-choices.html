چه زمانی از HashSet، SortedSet یا Dictionary استفاده می‌کنیم؟

پاسخ کوتاه مصاحبه‌ای

HashSet<T> برای membership و uniqueness سریع است؛ SortedSet<T> uniqueness را با ترتیب مرتب و range operation ترکیب می‌کند؛ Dictionary<TKey,TValue> وقتی هر key باید به یک value مرتبط نگاشت شود مناسب است.

مدل ذهنی ساده

مسئله را به سه سؤال تبدیل کنید: فقط می‌خواهم بدانم item وجود دارد؟ HashSet. باید itemهای یکتا همیشه مرتب باشند؟ SortedSet. برای هر key داده دیگری دارم؟ Dictionary. انتخاب بر نام collection نیست؛ بر operation اصلی و contract ترتیب است.

توضیح کامل

HashSet از hashing و equality استفاده می‌کند و ترتیب enumeration آن نباید contract برنامه باشد. SortedSet ساختار مرتب مبتنی بر comparer دارد، operationهای membership معمولاً O(log n) هستند و viewهای range فراهم می‌کند. Dictionary نیز hashing دارد ولی entry شامل key و value است. استفاده از Dictionary<T,bool> برای membership intent را ضعیف و حافظه اضافی مصرف می‌کند. comparer در هر سه باید با قواعد دامنه سازگار باشد.

C#
var tags = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
var ranks = new SortedSet<int> { 3, 1, 2 };
var prices = new Dictionary<string, decimal> { ["book"] = 12m };

رفتار مثال: برای حذف tagهای تکراری با مقایسه case-insensitive از HashSet استفاده می‌شود. برای leaderboard یکتا که همیشه براساس score مرتب و نیازمند Min/Max است SortedSet مناسب‌تر است. catalog قیمت به Dictionary نیاز دارد چون هر product code به decimal نگاشت می‌شود.

نکات کلیدی

  • HashSet پاسخ membership و uniqueness می‌دهد.
  • SortedSet ترتیب مرتب و range را حفظ می‌کند.
  • Dictionary رابطه key-to-value را مدل می‌کند.

اشتباهات رایج

  • وابستگی به ترتیب فعلی HashSet
  • استفاده از Dictionary به‌جای set.

جزئیات عمیق‌تر

اگر چند value برای یک key لازم است، Dictionary با collection value یا Lookup را بررسی کنید. اگر ترتیب insertion قرارداد است، type مناسب همان contract را صریح انتخاب کنید و به جزئیات implementation تکیه نکنید. هزینه comparer و mutation کلیدها نیز مانند Dictionary مهم است.

در پروژهٔ واقعی

برای dedup تگ HashSet، leaderboard مرتب SortedSet و catalog قیمت Dictionary انتخاب کنید.
