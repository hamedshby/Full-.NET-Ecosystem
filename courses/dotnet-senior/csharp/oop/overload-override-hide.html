تفاوت Overloading، Overriding و Method Hiding چیست؟

پاسخ کوتاه مصاحبه‌ای

Overloading انتخاب میان signatureهای هم‌نام در Compile Time است. Overriding پیاده‌سازی یک member virtual یا abstract را عوض می‌کند و انتخاب آن در Runtime انجام می‌شود. Method Hiding با new member پایه را براساس Static Type پنهان می‌کند.

مدل ذهنی ساده

سه پرسش جدا بپرسید: آیا چند method هم‌نام با parameterهای متفاوت داریم؟ Overloading. آیا call از reference پایه باید رفتار type واقعی object را اجرا کند؟ Overriding. آیا member جدید فقط وقتی متغیر با type مشتق دیده می‌شود انتخاب شود؟ Method Hiding. یکی‌کردن این سه باعث پاسخ مبهم می‌شود.

توضیح کامل

در Overloading، Compiler با typeهای قابل‌مشاهده و قواعد conversion بهترین signature را انتخاب می‌کند؛ Runtime Type آرگومان به‌تنهایی overload دیگری را فعال نمی‌کند. در Overriding، member پایه باید virtual یا abstract باشد و عضو مشتق با override همان slot مجازی را پیاده کند؛ dispatch با Runtime Type object انجام می‌شود. در Method Hiding، member مشتق slot تازه‌ای دارد و call براساس Static Type سمت چپ تعیین می‌شود. استفاده از new هشدار را صریح می‌کند ولی رفتار را polymorphic نمی‌سازد.

C#
class Base { public virtual string Name() => "Base"; }
class Child : Base { public override string Name() => "Child"; }
Base item = new Child();
Console.WriteLine(item.Name()); // Child

رفتار مثال: اگر Animal a = new Dog() باشد، a.Speak() نسخه Dog را اجرا می‌کند چون Speak override شده است. اما اگر Info با new پنهان شده باشد، a.Info() نسخه Animal را می‌خواند و ((Dog)a).Info() نسخه Dog را. overload Print(int) یا Print(string) نیز هنگام Compile براساس type آرگومان انتخاب می‌شود.

نکات کلیدی

  • Overloading به signature و Compile Time مربوط است.
  • Overriding از virtual dispatch و Runtime Type استفاده می‌کند.
  • Method Hiding به Static Type متغیر وابسته است.

اشتباهات رایج

  • برابر دانستن overload با polymorphism runtime
  • حذف override و پنهان‌سازی ناخواسته.

جزئیات عمیق‌تر

return type به‌تنهایی overload نمی‌سازد. در override باید accessibility و قرارداد base رعایت شود و امکان covariant return برای برخی reference return typeها وجود دارد. Method Hiding معمولاً در API عمومی غافلگیرکننده است؛ اگر polymorphism هدف است، طراحی virtual/override یا Composition روشن‌تر خواهد بود.

در پروژهٔ واقعی

برای extension point از override قراردادی استفاده کنید؛ overloadهای مبهم API را سخت می‌کنند.
