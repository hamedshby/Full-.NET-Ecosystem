تفاوت Value Type و Reference Type چیست؟

پاسخ کوتاه مصاحبه‌ای

Value Type خود داده را نگه می‌دارد و انتساب آن مقدار را کپی می‌کند؛ Reference Type یک ارجاع به شیء را نگه می‌دارد و انتساب، همان ارجاع را کپی می‌کند. محل stack یا heap تعریف این دو خانواده نیست.

توضیح کامل

در C# رفتار کپی، هویت و nullپذیری مهم‌تر از محل حافظه‌اند. structها معمولاً value type و classها reference type هستند. یک value type می‌تواند داخل شیء روی heap باشد و یک reference محلی روی stack قرار گیرد؛ بنابراین پاسخ مصاحبه را به semantics گره بزنید.

برای مدل‌های کوچک و بدون هویت مانند Money یک value object مناسب است؛ Entity دارای هویت معمولاً class است.

C#
int a = 10;
int b = a;
b++; // a همچنان 10 است

var first = new Person { Name = "Sara" };
var second = first;
second.Name = "Mina"; // first.Name نیز Mina است

نکات کلیدی

  • در C# رفتار کپی، هویت و nullپذیری مهم‌تر از محل حافظه‌اند
