چرا List به List قابل تبدیل نیست؟

پاسخ کوتاه مصاحبه‌ای

چون List هم T می‌خواند و هم T می‌نویسد؛ اگر List به List تبدیل می‌شد، می‌توانستیم Dog داخل آن اضافه کنیم و type safety بشکند.

توضیح کامل

interface فقط‌خواندنی مانند IEnumerable می‌تواند covariant باشد، زیرا ورودی T نمی‌پذیرد. invariance محدودیت بی‌دلیل نیست؛ از mutation ناسازگار جلوگیری می‌کند.

برای ورودی فقط‌خواندنی `IEnumerable` بگیرید؛ اگر mutation لازم است ownership را صریح طراحی کنید.

C#
List<Cat> cats = [new Cat()];
IEnumerable<Animal> animals = cats; // امن
// List<Animal> mutable = cats; // غیرمجاز؛ افزودن Dog ممکن بود

نکات کلیدی

  • interface فقط‌خواندنی مانند IEnumerable می‌تواند covariant باشد، زیرا ورودی T نمی‌پذیرد
  • invariance محدودیت بی‌دلیل نیست؛ از mutation ناسازگار جلوگیری می‌کند

اشتباهات رایج

  • حل با cast خطرناک یا کپی بی‌دلیل
  • یکی دانستن covariance array با ایمنی کامل.
