Genericها چه مشکلی را حل می‌کنند و چرا از object بهترند؟

پاسخ کوتاه مصاحبه‌ای

Genericها یک algorithm یا data structure را برای چند type با Type Safety مشترک می‌کنند. خطاهای type در Compile Time پیدا می‌شوند، castهای مصرف‌کننده حذف می‌شوند و برای Value Typeها معمولاً Boxing ناخواسته کاهش می‌یابد.

مدل ذهنی ساده

List<T> را ظرفی بدانید که type محتوای آن بخشی از قرارداد است. List<int> فقط int می‌پذیرد و هنگام خواندن int تحویل می‌دهد؛ نیازی نیست caller حدس بزند داخل object چه بوده است. T یک جای خالی بی‌قانون نیست؛ Compiler تمام استفاده‌ها را با همان type واقعی بررسی می‌کند.

توضیح کامل

پیش از Genericها، collection مبتنی بر object هم cast لازم داشت و هم امکان خطای Runtime ایجاد می‌کرد. Generic method مانند Max<T> منطق را یک بار بیان می‌کند و Compiler type argument را infer یا validate می‌کند. constraints قابلیت‌های قابل‌استفاده روی T را محدود می‌کنند. در CLR، constructed generic typeها در Runtime شناخته می‌شوند؛ این مدل با type erasure ساده یکسان نیست. مزیت Performance وابسته به workload است و نباید بدون اندازه‌گیری ادعای مطلق کرد.

C#
static T First<T>(IReadOnlyList<T> items)
    => items.Count > 0 ? items[0] : throw new InvalidOperationException();

int number = First(new[] { 10, 20 });

رفتار مثال: Stack<int> فقط int می‌گیرد و Pop نیز int برمی‌گرداند، پس cast و احتمال InvalidCastException حذف می‌شود. همان implementation برای Stack<Order> استفاده می‌شود. اگر نسخه قدیمی ArrayList باشد، افزودن string کنار int ممکن است تا زمان cast بعدی پنهان بماند و intها نیز Boxing شوند.

نکات کلیدی

  • Genericها Type Safety را به قرارداد type منتقل می‌کنند.
  • یک implementation برای چند type قابل‌استفاده می‌شود.
  • برای Value Typeها می‌توانند Boxing ناخواسته را کم کنند.

اشتباهات رایج

  • تصور تولید کد کاملاً جدا برای هر T در همهٔ حالات
  • generic کردن API بدون نیاز.

جزئیات عمیق‌تر

Generic همیشه بهترین abstraction نیست؛ اگر رفتار typeها واقعاً متفاوت است، یک T عمومی ممکن است شرط‌های فراوان بسازد. API را بر capability مشترک طراحی و کمترین constraint لازم را انتخاب کنید. برای مسیرهای حساس، allocation و generated code را با profiler و Benchmark بررسی کنید.

در پروژهٔ واقعی

repository یا pipeline typed خطاهای cast را از runtime به compile time منتقل می‌کند.

جمع‌بندی برای مصاحبه

reuse، type safety، حذف cast و کاهش boxing را همراه یک signature روشن بگویید.
