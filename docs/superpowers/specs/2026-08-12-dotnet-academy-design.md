# سند طراحی وب‌سایت آکادمی دات‌نت

تاریخ: ۱۴۰۵/۰۵/۲۱ (۱۲ اوت ۲۰۲۶)

## هدف محصول

ساخت نسخهٔ نخست وب‌سایت «آکادمی دات‌نت» به‌عنوان ویترین حرفه‌ای دوره‌های آموزشی فارسی در حوزهٔ .NET. ظاهر سایت از چیدمان کارت‌محور تصویر مرجع الهام می‌گیرد، اما هویت بصری مستقل، فارسی و قابل توسعه برای تبدیل‌شدن به یک مرجع بین‌المللی خواهد داشت.

نسخهٔ اول فقط یک صفحهٔ عمومی و بدون ورود کاربر است و صرفاً با HTML، CSS و JavaScript خالص ساخته می‌شود.

## هویت و جهت بصری

- نام برند: «آکادمی دات‌نت»
- لحن: حرفه‌ای، روشن، معتبر و مناسب توسعه‌دهندگان
- رنگ اصلی: نیلی و بنفش، همراه با فیروزه‌ای برای وضعیت‌های رایگان و موفق
- پس‌زمینه: روشن و تمیز در تم روشن؛ سرمه‌ای عمیق در تم تاریک
- تایپوگرافی: فونت فارسی خوانا با فونت‌های سیستمی به‌عنوان جایگزین
- طراحی: گوشه‌های نرم، سایه‌های کنترل‌شده، کادرهای ظریف و انیمیشن‌های کوتاه
- هیچ تصویر یا نشان تجاری متعلق به وب‌سایت مرجع کپی نمی‌شود؛ تصاویر بالای کارت‌ها با ترکیب CSS، تایپوگرافی و نمادهای سادهٔ اختصاصی ساخته می‌شوند.

## معماری صفحه

### ۱. هدر

هدر ثابت و نیمه‌شفاف شامل موارد زیر است:

- نشان و نام «آکادمی دات‌نت»
- پیوندهای «دوره‌ها»، «منابع» و «خبرنامه»
- انتخاب زبان فارسی/English
- دکمهٔ تغییر تم روشن و تاریک
- دکمهٔ «مشاهده دوره‌ها» به‌جای حساب کاربری یا «دوره‌های من»
- منوی جمع‌شونده در موبایل

پیوندها در نسخهٔ نخست به بخش مرتبط صفحه اسکرول می‌کنند. برای بخش‌های آینده، پیام کوتاه «به‌زودی» نمایش داده می‌شود.

### ۲. بخش معرفی

- عنوان اصلی: «مهارت‌های دات‌نت؛ از یادگیری تا تسلط»
- توضیح کوتاه دربارهٔ آموزش عمیق، پروژه‌محور و متناسب با بازار کار جهانی
- دو اقدام اصلی: «مشاهده دوره‌ها» و «آزمون رایگان»
- آمار اعتمادساز نمایشی و غیراغراق‌آمیز بر پایهٔ محتوای موجود، مانند تعداد دوره‌ها و فصل‌ها؛ از نمایش تعداد ساختگی دانشجو یا رضایت جلوگیری می‌شود.

### ۳. فهرست دوره‌ها

کارت‌ها در دسکتاپ سه‌ستونه، در تبلت دوستونه و در موبایل تک‌ستونه هستند. هر کارت شامل تصویر گرافیکی، وضعیت، عنوان، معرفی، ویژگی‌ها، برچسب‌های سطح و اقدام اصلی است.

دوره‌های نسخهٔ اول:

1. «مسیر حرفه‌ای Senior در ‎.NET»
   - ۵۸ فصل، ۸۷۹ پرسش
   - موضوعات: C#، .NET، ASP.NET Core، EF Core و طراحی سیستم
   - سطح: متوسط تا ارشد
2. «راهنمای طراحی سیستم»
   - وضعیت: به‌زودی
   - ۱۴ طراحی عملی و ۱۰ مصاحبهٔ آزمایشی
   - سطح: ارشد، رهبر فنی و معمار نرم‌افزار
3. «آزمون رایگان مصاحبه ‎.NET»
   - وضعیت: رایگان
   - آزمون تطبیقی و گزارش نقاط قوت و ضعف
   - سطح: مقدماتی تا ارشد
4. «دورهٔ ایمیلی Claude Code»
   - وضعیت: رایگان
   - برنامهٔ آموزشی ۱۰روزه برای استفادهٔ حرفه‌ای از Claude Code در توسعهٔ نرم‌افزار

از آنجا که صفحهٔ جزئیات یا بک‌اند در دامنهٔ نسخهٔ اول نیست، دکمه‌های کارت‌ها پیام مناسب «جزئیات این دوره به‌زودی اضافه می‌شود» نمایش می‌دهند. آزمون رایگان نیز در این نسخه معرفی می‌شود و اجرا نمی‌شود.

### ۴. بخش ارزش پیشنهادی

سه مزیت کوتاه:

- آموزش پروژه‌محور و کاربردی
- مسیر یادگیری شفاف برای سطوح مختلف
- تمرکز بر استانداردهای روز اکوسیستم .NET

### ۵. خبرنامه و فوتر

- فرم نمایشی عضویت با بررسی اولیهٔ قالب ایمیل
- پس از ثبت، پیام شفاف مبنی بر آزمایشی‌بودن نسخه نمایش داده می‌شود؛ هیچ داده‌ای ارسال یا ذخیره نمی‌شود.
- فوتر شامل نام برند، توضیح کوتاه، پیوندهای صفحه و سال جاری است.

## تعاملات و وضعیت‌ها

### تم

- تم اولیه از تنظیم سیستم‌عامل خوانده می‌شود.
- انتخاب کاربر در `localStorage` ذخیره می‌شود.
- کنترل تم دارای عنوان قابل‌فهم برای صفحه‌خوان است.

### زبان

- متن‌ها از یک شیء ترجمه در JavaScript خوانده می‌شوند تا افزودن زبان انگلیسی بدون بازنویسی ساختار ممکن باشد.
- فارسی زبان اولیه و کامل است.
- انتخاب English در نسخهٔ اول رابط را تغییر نمی‌دهد و پیام «نسخهٔ انگلیسی به‌زودی» نمایش می‌دهد.
- جهت سند در فارسی `rtl` باقی می‌ماند؛ زیرساخت تغییر `dir` برای نسخهٔ انگلیسی پیش‌بینی می‌شود.

### اعلان‌ها

پیام‌های کوتاه برای گزینه‌های به‌زودی، کارت‌های فاقد صفحهٔ جزئیات و فرم خبرنامه استفاده می‌شوند. اعلان‌ها قابل‌خواندن با صفحه‌خوان و بدون ایجاد مزاحمت هستند.

## ساختار فنی

- `index.html`: ساختار معنایی و محتوای صفحه
- `styles.css`: سیستم رنگ، چیدمان واکنش‌گرا، تم‌ها و انیمیشن‌ها
- `script.js`: منوی موبایل، تم، زبان، اسکرول، اعلان‌ها و اعتبارسنجی فرم
- بدون فریم‌ورک، ابزار build، وابستگی بیرونی یا بک‌اند
- داده‌های دوره‌ها در نسخهٔ اول مستقیماً در HTML قرار می‌گیرند تا صفحه بدون JavaScript نیز محتوای اصلی را نشان دهد.

## واکنش‌گرایی و دسترس‌پذیری

- طراحی از عرض ۳۲۰ پیکسل به بالا
- ناوبری کامل با صفحه‌کلید
- کنتراست مناسب در هر دو تم
- وضعیت فوکوس واضح
- استفاده از عناصر معنایی، عنوان‌ها، labelها و ویژگی‌های ARIA فقط در محل لازم
- رعایت `prefers-reduced-motion`
- جلوگیری از اسکرول افقی و کوچک‌بودن اهداف لمسی

## سئو و کیفیت

- عنوان و توضیح فارسی معنادار برای صفحه
- ساختار درست headingها و داده‌های محتوایی قابل ایندکس
- متادیتای پایهٔ Open Graph بدون تصویر ساختگی
- آیکن سادهٔ سایت با CSS/کاراکتر یا data URI در صورت مناسب‌بودن
- بارگذاری سریع و بدون وابستگی سنگین

## مدیریت خطا و محدودیت‌ها

- نبود `localStorage` مانع استفاده از سایت نمی‌شود و فقط ذخیرهٔ تنظیم تم غیرفعال می‌شود.
- فرم خبرنامه ورودی خالی یا نامعتبر را با پیام فارسی مشخص می‌کند.
- JavaScript یک قابلیت تکمیلی است؛ متن دوره‌ها و ناوبری پایه بدون آن قابل مشاهده می‌ماند.
- ورود، ثبت‌نام، پرداخت، پخش ویدئو، صفحهٔ جزئیات دوره، اجرای آزمون و ذخیرهٔ خبرنامه خارج از دامنهٔ نسخهٔ اول هستند.

## معیارهای پذیرش

1. صفحه از نظر ساختار کلی مشابه مرجع، اما دارای هویت بصری مستقل باشد.
2. تمام متن قابل مشاهده فارسی و راست‌چین باشد.
3. چهار دورهٔ تعیین‌شده نمایش داده شوند.
4. تم روشن و تاریک کار کند و انتخاب تم حفظ شود.
5. زیرساخت چندزبانه وجود داشته باشد و وضعیت نسخهٔ انگلیسی شفاف باشد.
6. سایت در موبایل، تبلت و دسکتاپ بدون شکست چیدمان قابل استفاده باشد.
7. هیچ قابلیت ورود یا هویت کاربری نمایش داده نشود.
8. سایت فقط از HTML، CSS و JavaScript تشکیل شود.
9. خطای نحوی JavaScript وجود نداشته باشد و تعاملات اصلی با صفحه‌کلید قابل استفاده باشند.
10. محتوای اصلی بدون JavaScript نیز قابل خواندن باشد.

- بررسی چیدمان در عرض‌های موبایل، تبلت و دسکتاپ
- بررسی خوانایی و کنتراست هر دو تم
- بررسی صفحه در حالت JavaScript غیرفعال برای اطمینان از نمایش محتوای اصلی
