## معماری صفحات

هر سؤال یک فایل HTML مستقل و محتوای اصلی آن در خود HTML است. فایل‌های مشترک زیر ظاهر و تعاملات را فراهم می‌کنند:

- `course.css`: چیدمان پوستهٔ مطالعه، ناوبری فصل، پاسخ، کدها، تم‌ها و واکنش‌گرایی

JavaScript نقش progressive enhancement دارد. سؤال، پاسخ، فهرست فصل و پیوند سؤال قبل/بعد بدون JavaScript قابل استفاده می‌مانند.
