# طراحی یکپارچه‌سازی دوره Microservices

## هدف

پروژه `Full .NET Ecosystem` باید یک دورهٔ مستقل برای `Microservices` داشته باشد که تجربهٔ مطالعهٔ آن با دورهٔ Senior `.NET` هماهنگ باشد: فهرست فصل‌ها در سمت راست، محتوای درس در سمت چپ و تجربهٔ مناسب موبایل. منبع اولیهٔ فهرست و ۲۳ درس موجود، پروژهٔ کناری `MicroService` است.

## دامنه

- تمام ۱۵۱ سرفصل فعلی پروژه `MicroService` در همان ترتیب و در ۱۸ فصل نمایش داده می‌شوند.
- ۲۳ سرفصل دارای فایل محتوا به صفحهٔ قابل مطالعه تبدیل می‌شوند.
- ۱۲۸ سرفصل فاقد فایل با نشان «به‌زودی» نمایش داده می‌شوند و لینک تعاملی ندارند.
- محتوای جدید برای ۱۲۸ درس نوشته نمی‌شود.
- پروژهٔ `MicroService` حذف یا ویرایش نمی‌شود و تنها منبع انتقال است.

## ساختار فایل‌ها

دوره در `courses/microservices/` قرار می‌گیرد:

- `course-navigation.js`: منبع واحد ۱۸ فصل و ۱۵۱ سرفصل، وضعیت دسترسی و مسیر صفحات.
- `course.js`: تم، فهرست موبایل و تعامل‌های مشترک.
- `course.css`: Layout دو ستونه و ظاهر مشترک دوره.
- `lessons/<chapter-id>.html`: صفحات مستقل ۲۳ درس موجود.

صفحات مستقل باعث می‌شوند URL هر درس قابل اشتراک، Bookmark و Index باشد و اجرای دوره به `fetch` یا پروژهٔ کناری وابسته نباشد.

## فهرست و وضعیت دسترسی

فصل‌ها و سرفصل‌ها عیناً از Sidebar فعلی `MicroService/index.html` استخراج می‌شوند. فصل‌ها عبارت‌اند از:

1. Relationship between Microservices
2. Synchronous Communication
3. Asynchronous Communication
4. RabbitMQ
5. Apache Kafka
6. RabbitMQ vs Kafka
7. MassTransit
8. Messaging Patterns
9. Reliability Patterns
10. Distributed Transactions
11. Outbox Pattern
12. Inbox Pattern
13. Saga Pattern
14. Idempotency
15. Monitoring
16. Security
17. Performance
18. Practical Project

شناسه‌های دارای محتوا عبارت‌اند از `ch1-1` تا `ch1-4`، `ch2-1`، `ch2-2`، `ch2-2-1`، `ch2-3`، `ch2-4`، `ch3-1` تا `ch3-5`، `ch4-1` تا `ch4-6` و `ch5-1` تا `ch5-3`. وجود فایل، معیار وضعیت «در دسترس» است؛ باقی شناسه‌ها «به‌زودی» هستند.

## تجربهٔ کاربری

- Desktop: Sidebar ثابت و قابل پیمایش در سمت راست و محتوای درس در سمت چپ.
- Mobile: Sidebar بالای محتوا قرار می‌گیرد و پس از آماده‌شدن JavaScript با دکمهٔ «فهرست فصل‌ها» باز و بسته می‌شود. بدون JavaScript فهرست همچنان قابل مشاهده است.
- فصل درس جاری باز و لینک درس جاری با `aria-current="page"` مشخص می‌شود.
- موارد «به‌زودی» با متن غیرلینکی و Badge مشخص می‌شوند؛ ظاهر آن‌ها نباید به اشتباه قابل کلیک به نظر برسد.
- هر صفحه دارای Skip Link، عنوان یکتا، توضیح متا، Breadcrumb و پیمایش درس قبلی/بعدی میان درس‌های موجود است.
- تم روشن/تیره و `prefers-reduced-motion` پشتیبانی می‌شوند.
- اصطلاحات رسمی انگلیسی مطابق `RTK.md` بدون ترجمه باقی می‌مانند و در متن RTL با `bdi` یا `code` ایزوله می‌شوند.

## انتقال محتوا

ساختار معنایی هر فایل موجود از `MicroService/chapters/` حفظ می‌شود، اما Shell صفحه، Header، Sidebar، Breadcrumb و Pager با الگوی دوره‌های `Full .NET Ecosystem` ساخته می‌شوند. لینک‌ها و assetها به مسیرهای داخلی پروژهٔ مقصد اصلاح می‌شوند. محتوای آموزشی در این مرحله بازنویسی نمی‌شود مگر برای رفع HTML نامعتبر یا مسیر شکسته.

## اتصال به صفحهٔ اصلی

لینک «شروع مطالعه» کارت `Microservices` به `courses/microservices/lessons/ch1-1.html` تغییر می‌کند. دوره پس از انتقال هیچ وابستگی اجرایی به `../MicroService/` ندارد.

## آزمون و پذیرش

- فهرست مرکزی دقیقاً ۱۸ فصل و ۱۵۱ شناسهٔ یکتا دارد.
- دقیقاً ۲۳ درس در دسترس و ۱۲۸ درس «به‌زودی» هستند.
- برای هر درس در دسترس، فایل HTML متناظر وجود دارد و تمام لینک‌های محلی resolve می‌شوند.
- تمام صفحات Shell مشترک، Sidebar سمت راست، محتوای سمت چپ، عنوان، Breadcrumb و Pager معتبر دارند.
- درس‌های «به‌زودی» لینک فعال تولید نمی‌کنند.
- کارت صفحهٔ اصلی اولین درس داخلی را باز می‌کند.
- آزمون‌های دسترس‌پذیری ساختاری، Responsive CSS، تعامل منو و تم اجرا می‌شوند.
- آزمون‌های موجود صفحهٔ اصلی نباید Regression داشته باشند.

## خارج از دامنه

- تکمیل محتوای ۱۲۸ درس «به‌زودی».
- تغییر سرفصل‌ها یا ترتیب منبع.
- حذف پروژهٔ قدیمی `MicroService`.
- ایجاد Backend، پایگاه داده، حساب کاربری یا Progress Tracking.
