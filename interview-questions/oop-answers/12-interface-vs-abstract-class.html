پاسخ کوتاه مناسب مصاحبه

An interface mainly defines a contract and a class can implement multiple interfaces. An abstract class is a base class that can provide shared implementation and hold state. A class can inherit from only one class.

ترجمهٔ فارسی

Interface عمدتاً یک Contract را تعریف می‌کند و یک Class می‌تواند چند Interface را پیاده‌سازی کند. Abstract Class یک Base Class است که می‌تواند پیاده‌سازی مشترک ارائه کند و State داشته باشد. یک Class فقط می‌تواند از یک Class ارث‌بری کند.

نکته: Interface معمولاً برای Contract چندگانه مناسب‌تر است؛ Abstract Class می‌تواند برای Shared State/Behavior مناسب باشد.
