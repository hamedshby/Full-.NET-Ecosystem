پاسخ کوتاه مناسب مصاحبه

Overloading means multiple methods have the same name but different parameter signatures. Overriding means a derived class provides a new implementation for an inherited virtual or abstract member with the same signature.

ترجمهٔ فارسی

Overloading یعنی چند متد نام یکسان ولی Signature مربوط به Parameterهای متفاوت داشته باشند. Overriding یعنی Derived Class برای یک عضو virtual یا abstract به‌ارث‌رسیده، پیاده‌سازی جدیدی با همان Signature ارائه کند.

void Pay(int amount) { }
void Pay(decimal amount) { } // overloading

public override void Pay() { } // overriding
نکته: Overloading معمولاً در Compile Time انتخاب می‌شود؛ Overriding پایهٔ Runtime Polymorphism است.
