پاسخ کوتاه مناسب مصاحبه

A Singleton should not directly capture a Scoped dependency because the shorter-lived dependency can effectively live as long as the Singleton. This is called a captive dependency. Usually the lifetimes should be redesigned; when appropriate, IServiceScopeFactory can create an explicit scope.

ترجمهٔ فارسی

یک Singleton نباید مستقیماً یک Dependency از نوع Scoped را نگه دارد، زیرا آن Dependency کوتاه‌عمر عملاً ممکن است به‌اندازهٔ Singleton زنده بماند. به این وضعیت Captive Dependency گفته می‌شود. معمولاً باید Lifetimeها دوباره طراحی شوند؛ در صورت نیاز، IServiceScopeFactory می‌تواند یک Scope صریح ایجاد کند.

using var scope = _scopeFactory.CreateScope();
var dbContext = scope.ServiceProvider.GetRequiredService<MyDbContext>();
نکته: این خطا را معمولاً DI Container هنگام Runtime یا Validation تشخیص می‌دهد؛ نه Compile Time.
