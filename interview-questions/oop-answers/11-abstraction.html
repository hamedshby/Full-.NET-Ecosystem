پاسخ کوتاه مناسب مصاحبه

Abstraction means exposing essential behavior while hiding unnecessary implementation details. An abstract class cannot be instantiated directly. It can contain abstract members and shared implemented members. We can use an abstract Payment when only concrete payment types should be created.

ترجمهٔ فارسی

Abstraction یعنی رفتارهای ضروری را نمایش دهیم و جزئیات غیرضروری پیاده‌سازی را پنهان کنیم. از یک abstract class نمی‌توان مستقیماً نمونه ساخت. این Class می‌تواند اعضای abstract و اعضای پیاده‌سازی‌شدهٔ مشترک داشته باشد. زمانی از Payment انتزاعی استفاده می‌کنیم که فقط Typeهای مشخص پرداخت باید قابل‌ساخت باشند.

نکته: Abstraction یک مفهوم طراحی است؛ abstract class یکی از ابزارهای پیاده‌سازی آن در C# است.
