پاسخ کوتاه مناسب مصاحبه

A constructor is a special member of a class with the same name as the class and no return type. We use it to initialize an object. It can receive parameters, validate them, and ensure that the object starts in a valid state.

ترجمهٔ فارسی

Constructor عضو ویژه‌ای از Class است که نامی یکسان با Class دارد و Return Type ندارد. از آن برای مقداردهی اولیهٔ Object استفاده می‌کنیم. Constructor می‌تواند Parameter دریافت کند، آن‌ها را اعتبارسنجی کند و مطمئن شود که Object از ابتدا در یک State معتبر ساخته می‌شود.

public Payment(decimal amount, string referenceNumber)
{
    if (amount <= 0)
        throw new ArgumentOutOfRangeException(nameof(amount));

    if (string.IsNullOrWhiteSpace(referenceNumber))
        throw new ArgumentException("Reference number is required.");

    Amount = amount;
    ReferenceNumber = referenceNumber;
}
نکته: Constructor می‌تواند از همان لحظهٔ ساخت، قوانین اولیه را enforce کند.
