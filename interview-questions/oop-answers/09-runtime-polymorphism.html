پاسخ کوتاه مناسب مصاحبه

If Pay is virtual in Payment and overridden in CardPayment, Card Payment will be printed. The reference type is Payment, but the runtime object is CardPayment, so the overridden implementation is selected at runtime. This is runtime polymorphism.

ترجمهٔ فارسی

اگر Pay در Payment به‌صورت virtual تعریف و در CardPayment override شده باشد، عبارت Card Payment چاپ می‌شود. Type مربوط به Reference برابر Payment است، اما Object واقعی در Runtime از نوع CardPayment است؛ بنابراین پیاده‌سازی overrideشده در Runtime انتخاب می‌شود. این همان Runtime Polymorphism است.

public class Payment
{
    public virtual void Pay() => Console.WriteLine("Payment");
}

public class CardPayment : Payment
{
    public override void Pay() => Console.WriteLine("Card Payment");
}

Payment payment = new CardPayment();
payment.Pay(); // Card Payment
نکته: نوع Reference و نوع واقعی Runtime می‌توانند متفاوت باشند.
