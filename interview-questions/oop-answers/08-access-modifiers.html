پاسخ کوتاه مناسب مصاحبه

private members are accessible only inside the declaring class. protected members are accessible inside the declaring class and derived classes. public members are accessible from any code that can access the type.

ترجمهٔ فارسی

اعضای private فقط داخل Class تعریف‌کننده قابل‌دسترسی‌اند. اعضای protected داخل Class تعریف‌کننده و Derived Classها در دسترس‌اند. اعضای public از هر کدی که به آن Type دسترسی داشته باشد، قابل‌استفاده‌اند.

نکته: protected معمولاً برای اعضایی است که باید برای Classهای مشتق قابل استفاده باشند.
