پاسخ کوتاه مناسب مصاحبه

A value type stores its value directly, so copying it copies the value. A reference type variable stores a reference to an object, so copying the variable copies the reference and both variables can refer to the same object. Memory placement depends on context; the simple rule value type = stack and reference type = heap is not always correct.

ترجمهٔ فارسی

Value Type مقدارش را مستقیماً نگه می‌دارد؛ بنابراین کپی‌کردن آن، خود مقدار را کپی می‌کند. متغیر Reference Type یک Reference به Object نگه می‌دارد؛ پس کپی متغیر، Reference را کپی می‌کند و هر دو متغیر می‌توانند به همان Object اشاره کنند. محل قرارگیری در Memory به Context بستگی دارد و قانون سادهٔ «Value Type روی Stack و Reference Type روی Heap» همیشه درست نیست.

نکته: مهم‌ترین تفاوت مصاحبه‌ای، Copy Semantics است؛ بحث Stack و Heap را مطلق بیان نکنید.
