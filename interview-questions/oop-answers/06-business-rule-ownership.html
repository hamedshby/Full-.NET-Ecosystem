پاسخ کوتاه مناسب مصاحبه

The BankAccount domain object should own that business rule because it is responsible for protecting its own state. With encapsulation, the rule stays close to the data it protects, so callers cannot accidentally bypass it.

ترجمهٔ فارسی

BankAccount Domain Object باید مالک این Business Rule باشد، زیرا مسئول محافظت از State خودش است. با Encapsulation، قانون نزدیک داده‌ای می‌ماند که از آن محافظت می‌کند؛ بنابراین Callerها نمی‌توانند ناخواسته آن را دور بزنند.

نکته: قانونی که مستقیماً Object را حفظ می‌کند بهتر است داخل خود آن Domain Object باشد.
