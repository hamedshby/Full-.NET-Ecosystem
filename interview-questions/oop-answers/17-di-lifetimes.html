پاسخ کوتاه مناسب مصاحبه

Transient creates a new instance each time the service is resolved. Scoped creates one instance per scope; in ASP.NET Core an HTTP request usually represents one scope. Singleton uses one instance for the entire application lifetime.

ترجمهٔ فارسی

Transient هر بار که Service دریافت می‌شود یک نمونهٔ جدید می‌سازد. Scoped برای هر Scope یک نمونه می‌سازد؛ در ASP.NET Core معمولاً هر HTTP Request یک Scope محسوب می‌شود. Singleton در تمام طول عمر Application فقط از یک نمونه استفاده می‌کند.

نکته: Scoped یعنی per-scope؛ HTTP Request فقط رایج‌ترین نمونهٔ Scope در ASP.NET Core است.
