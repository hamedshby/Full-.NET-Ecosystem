پاسخ کوتاه مناسب مصاحبه

A record is useful for data-centric types where value-based equality is important. Records are commonly used with immutable-style designs, but they are not required to be immutable. A normal class uses reference-based equality by default unless equality is customized.

ترجمهٔ فارسی

Record برای Typeهای Data-centric مناسب است که Value-based Equality در آن‌ها اهمیت دارد. Recordها معمولاً در طراحی‌های Immutable-style استفاده می‌شوند، اما اجباری نیست که Immutable باشند. یک Class معمولی، تا زمانی که Equality شخصی‌سازی نشده باشد، به‌صورت پیش‌فرض از Reference-based Equality استفاده می‌کند.

public record Person(string Name, int Age);

var p1 = new Person("Hamed", 40);
var p2 = new Person("Hamed", 40);
Console.WriteLine(p1 == p2); // true
نکته: هدف اصلی Record فقط Immutable بودن نیست؛ Value Equality و Data-centric Modeling مهم‌ترند.
