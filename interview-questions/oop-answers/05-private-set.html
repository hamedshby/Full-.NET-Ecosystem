پاسخ کوتاه مناسب مصاحبه

Because the class should be responsible for protecting its own state. A private setter prevents outside code from changing Balance directly. Operations such as Withdraw can enforce business rules first and keep the object in a valid state.

ترجمهٔ فارسی

زیرا خود Class باید مسئول محافظت از State داخلی‌اش باشد. private setter مانع تغییر مستقیم Balance توسط کد بیرونی می‌شود. عملیاتی مانند Withdraw ابتدا Business Ruleها را اعمال می‌کنند و سپس Object را در State معتبر نگه می‌دارند.

نکته: این همان ترکیب responsibility + business rule + encapsulation است.
