پاسخ کوتاه مناسب مصاحبه

A class defines a type and describes its data and behavior. An object is a runtime instance of that class. Different objects created from the same class can hold different state.

ترجمهٔ فارسی

Class یک Type را تعریف می‌کند و داده‌ها و رفتار آن را توضیح می‌دهد. Object نمونه‌ای از آن Class در زمان اجرا است. Objectهای متفاوتی که از یک Class ساخته می‌شوند، می‌توانند State متفاوتی داشته باشند.

public class Payment
{
    public decimal Amount { get; set; }
}

var p1 = new Payment();
var p2 = new Payment();
نکته: Class تعریف نوع است و Object نمونه‌ای واقعی از آن نوع در زمان اجراست.
