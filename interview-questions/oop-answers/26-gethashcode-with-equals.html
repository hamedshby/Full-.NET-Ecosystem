پاسخ کوتاه مناسب مصاحبه

Because equal objects must return the same hash code. Hash-based collections such as Dictionary and HashSet use GetHashCode() to locate a bucket and then use equality checks, so GetHashCode() must be consistent with Equals().

ترجمهٔ فارسی

زیرا Objectهای برابر باید Hash Code یکسانی برگردانند. Collectionهای مبتنی بر Hash مانند Dictionary و HashSet ابتدا با GetHashCode() یک Bucket را پیدا و سپس Equality را بررسی می‌کنند؛ بنابراین GetHashCode() باید با Equals() سازگار باشد.

نکته: اگر a.Equals(b) برابر true باشد، Hash Code آن دو نیز باید یکسان باشد.
