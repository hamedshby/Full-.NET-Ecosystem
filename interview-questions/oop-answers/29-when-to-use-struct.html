پاسخ کوتاه مناسب مصاحبه

Use a struct for small, value-like data that does not need object identity or class inheritance. Structs are often a good fit when value semantics are more natural, and they are commonly designed to be immutable.

ترجمهٔ فارسی

برای داده‌های کوچک و Value-like که به Object Identity یا Class Inheritance نیاز ندارند، از Struct استفاده کنید. وقتی Value Semantics طبیعی‌تر باشد، Struct معمولاً انتخاب مناسبی است و اغلب به‌شکل Immutable طراحی می‌شود.

public readonly struct Point
{
    public int X { get; }
    public int Y { get; }

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }
}
نکته: کوچک‌بودن داده به‌تنهایی کافی نیست؛ Value-like بودن و نداشتن Identity مهم‌تر است.
