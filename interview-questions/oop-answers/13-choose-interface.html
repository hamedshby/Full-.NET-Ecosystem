پاسخ کوتاه مناسب مصاحبه

Use an interface when you mainly need a contract, multiple unrelated implementations, or flexible substitution. Use an abstract class when closely related types need shared behavior or shared state.

ترجمهٔ فارسی

وقتی عمدتاً به یک Contract، چند پیاده‌سازی نامرتبط یا جایگزینی انعطاف‌پذیر نیاز دارید، Interface را انتخاب کنید. وقتی Typeهای نزدیک به هم به رفتار یا State مشترک نیاز دارند، Abstract Class مناسب‌تر است.

نکته: Interface وابستگی را به یک Contract یا قابلیت می‌بندد، نه به یک Hierarchy مشخص.
