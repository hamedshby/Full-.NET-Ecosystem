پاسخ کوتاه مناسب مصاحبه

Reference equality checks whether two references point to the same object instance. Value equality checks whether two objects are logically equal based on their values, even if they are different instances.

ترجمهٔ فارسی

Reference Equality بررسی می‌کند که آیا دو Reference به یک نمونهٔ واحد از Object اشاره می‌کنند یا نه. Value Equality بررسی می‌کند که آیا دو Object بر اساس مقادیرشان از نظر منطقی برابرند، حتی اگر نمونه‌های متفاوتی باشند.

var a = new Person { Name = "Hamed" };
var b = a;
ReferenceEquals(a, b); // true

var x = new Person { Name = "Hamed" };
var y = new Person { Name = "Hamed" };
ReferenceEquals(x, y); // false
نکته: کپی‌کردن یک Reference با Equality یکی نیست؛ Equality دربارهٔ مقایسه است، نه صرفاً Assignment.
