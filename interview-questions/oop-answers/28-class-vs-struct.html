پاسخ کوتاه مناسب مصاحبه

A class is a reference type, while a struct is a value type. Copying a class variable copies the reference; copying a struct copies its value. Classes support class inheritance, while structs cannot inherit from another class or struct.

ترجمهٔ فارسی

Class یک Reference Type است، درحالی‌که Struct یک Value Type است. کپی متغیر Class، Reference را کپی می‌کند؛ اما کپی Struct مقدارش را کپی می‌کند. Class از Class Inheritance پشتیبانی می‌کند، ولی Struct نمی‌تواند از Class یا Struct دیگری ارث‌بری کند.

نکته: Struct می‌تواند Interface پیاده‌سازی کند، اما از Class یا Struct دیگری ارث‌بری نمی‌کند.
