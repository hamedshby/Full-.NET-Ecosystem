پاسخ کوتاه مناسب مصاحبه

== is an operator and its behavior depends on the type and whether the operator is overloaded. Equals() is a method that can be overridden to define logical value equality. For many ordinary reference types, the default behavior is reference equality, while types such as string provide value-based equality.

ترجمهٔ فارسی

== یک Operator است و رفتارش به Type و Overload شدن آن بستگی دارد. Equals() متدی است که می‌توان آن را برای تعریف Logical Value Equality، override کرد. رفتار پیش‌فرض بسیاری از Reference Typeهای معمولی Reference Equality است، اما Typeهایی مانند string مقایسهٔ مبتنی بر مقدار دارند.

نکته: نمی‌توان گفت == همیشه یعنی Reference Equality و Equals() همیشه یعنی Value Equality؛ رفتار به Type و پیاده‌سازی آن بستگی دارد.
