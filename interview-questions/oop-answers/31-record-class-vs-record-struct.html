پاسخ کوتاه مناسب مصاحبه

record class is a reference type, while record struct is a value type. Both provide generated value-based equality, but their copy semantics differ: a record class variable copies a reference, while a record struct copies its value.

ترجمهٔ فارسی

record class یک Reference Type و record struct یک Value Type است. هر دو Value-based Equality تولیدشده دارند، اما Copy Semantics آن‌ها متفاوت است: متغیر record class یک Reference را کپی می‌کند، درحالی‌که record struct مقدارش را کپی می‌کند.

public record Person(string Name);
public record struct Point(int X, int Y);
نکته: هر دو Record هستند و Equality مناسب تولید می‌کنند، اما یکی Reference Type و دیگری Value Type است.
