پاسخ کوتاه مناسب مصاحبه

Keep the setter private and expose methods such as Deposit and Withdraw. Those methods validate the requested operation before changing Balance. This keeps the object in a valid state and prevents external code from bypassing business rules.

ترجمهٔ فارسی

setter را private نگه می‌داریم و متدهایی مانند Deposit و Withdraw ارائه می‌کنیم. این متدها پیش از تغییر Balance، عملیات درخواستی را اعتبارسنجی می‌کنند. در نتیجه Object در State معتبر باقی می‌ماند و کد بیرونی نمی‌تواند Business Ruleها را دور بزند.

public class BankAccount
{
    public decimal Balance { get; private set; }

    public void Deposit(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentOutOfRangeException(nameof(amount));
        Balance += amount;
    }

    public void Withdraw(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentOutOfRangeException(nameof(amount));
        if (amount > Balance)
            throw new InvalidOperationException("Insufficient balance.");
        Balance -= amount;
    }
}
نکته: به‌جای set مستقیم، تغییر State از مسیر متدهای معنی‌دار دامنه انجام می‌شود.
