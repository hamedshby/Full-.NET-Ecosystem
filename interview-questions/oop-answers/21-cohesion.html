پاسخ کوتاه مناسب مصاحبه

Cohesion means how closely related the responsibilities and members of a class are. High cohesion means a class focuses on a clear responsibility, which makes the code easier to understand, test, and maintain.

ترجمهٔ فارسی

Cohesion نشان می‌دهد مسئولیت‌ها و اعضای یک Class چقدر به یکدیگر مرتبط‌اند. High Cohesion یعنی یک Class روی مسئولیتی روشن تمرکز دارد؛ بنابراین فهم، تست و نگهداری کد آسان‌تر می‌شود.

نکته: هرچه اعضای یک Class بیشتر حول یک مسئولیت مشخص باشند، Cohesion آن بالاتر است.
