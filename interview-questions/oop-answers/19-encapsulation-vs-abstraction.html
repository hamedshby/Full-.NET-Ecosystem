پاسخ کوتاه مناسب مصاحبه

Encapsulation is about protecting and controlling an object's internal state and implementation. Abstraction is about exposing only the essential operations while hiding unnecessary complexity. In short: encapsulation protects the inside; abstraction simplifies what the outside needs to see.

ترجمهٔ فارسی

Encapsulation دربارهٔ محافظت و کنترل State داخلی و پیاده‌سازی یک Object است. Abstraction فقط عملیات ضروری را نمایش می‌دهد و پیچیدگی غیرضروری را پنهان می‌کند. خلاصه اینکه Encapsulation از درون محافظت می‌کند و Abstraction چیزی را که بیرون باید ببیند ساده می‌کند.

public interface IPaymentGateway
{
    Task PayAsync(decimal amount);
}

// Caller knows what operation exists, not the internal implementation.
نکته: Encapsulation → protect state؛ Abstraction → hide unnecessary complexity.
