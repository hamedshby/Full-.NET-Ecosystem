پاسخ کوتاه مناسب مصاحبه

A field stores data directly. A property provides controlled access to data through get and set accessors. Properties support encapsulation because we can restrict or validate how the state is read or changed.

ترجمهٔ فارسی

Field داده را مستقیماً نگه می‌دارد. Property از طریق Accessorهای get و set دسترسی کنترل‌شده به داده را فراهم می‌کند. Property از Encapsulation پشتیبانی می‌کند، زیرا می‌توانیم نحوهٔ خواندن یا تغییر State را محدود یا اعتبارسنجی کنیم.

نکته: Field مستقیماً داده را نگه می‌دارد؛ Property امکان کنترل دسترسی و تغییر State را می‌دهد.
